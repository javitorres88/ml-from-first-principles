Module 14 · Classical ML

Support Vector Machines & Kernels

Maximum-margin classifiers derived from geometry, the primal and dual problems, KKT conditions, soft margins with slack variables, and the kernel trick that makes linear machines nonlinear.

📚 Source: Lecture Notes 12 ⏱ 75 min 🧪 2 interactive labs 🐍 3 implementations

◎ Learning objectives

By the end of this module you should be able to:

  • Derive the margin width 2/‖w‖ for a separating hyperplane.
  • Convert the max-margin problem into the convex primal and then the dual.
  • Explain why only support vectors have non-zero α and what KKT complementary slackness implies.
  • Derive the soft-margin formulation and interpret the box constraint C.
  • Use the kernel trick to classify non-linearly separable data and tune C and γ.

1 Intuition

Classification, recapitulated

Every supervised classifier in this course minimises a cost of the same shape:

$$ \min_{\boldsymbol\theta}\; g(\boldsymbol\theta, f) = \sum_{i=1}^{N}\ell\big(f(\boldsymbol\theta,\mathbf{x}_i), y_i\big) + \lambda\cdot\text{Complexity}(f) $$

A linear classifier uses the decision rule $f(\mathbf{x}) = \langle\mathbf{w},\mathbf{x}\rangle + b$, whose zero set is a hyperplane: a line in 2-D, a plane in 3-D, and a hyperplane beyond that. The vector $\mathbf{w}$ is normal to the plane; $b$ shifts it.

But infinitely many lines separate two separable classes. Which one should we pick? The support vector machine answers: the one with the largest margin — the widest empty band between the classes. The intuition is that a boundary with room to spare on both sides is the one least likely to be wrong about a new point near the edge.

The geometry of the margin

Take the two parallel supporting hyperplanes $\langle\mathbf{w},\mathbf{x}\rangle + b = \pm 1$. Since $\mathbf{w}$ is normal to both, the perpendicular distance between them is $2/\|\mathbf{w}\|$. Maximising the margin means minimising $\|\mathbf{w}\|$:

$$ \max_{\mathbf{w},b}\frac{1}{\|\mathbf{w}\|} \quad\text{subject to}\quad y_i\big(\langle\mathbf{x}_i,\mathbf{w}\rangle + b\big) \ge 1 $$

Squaring and halving gives the standard convex form $\min \frac12\|\mathbf{w}\|^2$ subject to the same constraints. The quadratic objective matters: it is convex, so any local minimum is global, and there is no local-minimum trap as in neural networks.

Primal and dual

Rather than solving the constrained primal directly, we solve its Lagrangian dual, which involves the data only through inner products:

$$ \max_{\boldsymbol\alpha}\; -\frac12\sum_{i}\sum_{j}\alpha_i\alpha_jy_iy_j\langle\mathbf{x}_i,\mathbf{x}_j\rangle + \sum_i\alpha_i \quad\text{subject to}\quad \sum_i\alpha_iy_i = 0,\;\; \alpha_i \ge 0 $$

The Karush–Kuhn–Tucker (KKT) conditions guarantee the saddle point is optimal. Two consequences are the whole point of the module:

  • Sparsity. Complementary slackness says $\alpha_i\big[y_i(\langle\mathbf{w},\mathbf{x}_i\rangle+b)-1\big] = 0$, so $\alpha_i \gt 0$ only for points exactly on the margin. Those are the support vectors; every other point has $\alpha_i = 0$ and could be deleted without changing the model.
  • Kernels. Because the data enters only as $\langle\mathbf{x}_i,\mathbf{x}_j\rangle$, we can replace that inner product with any kernel $K(\mathbf{x}_i,\mathbf{x}_j)$ — implicitly working in a much higher-dimensional feature space without ever computing the mapping.

Soft margins

Real data overlaps. The hard-margin problem then has no feasible solution, so we introduce slack variables $\xi_i \ge 0$ that allow individual points to violate the margin, and charge for them:

$$ \min_{\mathbf{w},b,\boldsymbol\xi}\; \frac12\|\mathbf{w}\|^2 + C\sum_i\xi_i \quad\text{subject to}\quad y_i\big(\langle\mathbf{x}_i,\mathbf{w}\rangle+b\big) \ge 1-\xi_i,\;\; \xi_i\ge0 $$

The box constraint $C$ sets the exchange rate between a wide margin and tolerated violations. Large $C$: few violations allowed, narrow margin, risk of overfitting. Small $C$: wide margin, more violations, more regularization. The soft-margin problem is always feasible — $w = b = 0$, $\xi_i = 1$ is a valid (bad) solution — which is why it always returns a model.

The kernel trick

If the data is not linearly separable in the input space, map it into a higher-dimensional space where it is, find a separating hyperplane there, and project the boundary back. The trick is that you never compute the mapping $\phi$: you only need the kernel $K(\mathbf{x},\mathbf{z}) = \langle\phi(\mathbf{x}),\phi(\mathbf{z})\rangle$.

Kernel$K(\mathbf{x},\mathbf{z})$Notes
Linear$\langle\mathbf{x},\mathbf{z}\rangle$ordinary SVM; good for text with many features
Polynomial$(\langle\mathbf{x},\mathbf{z}\rangle + c)^d$explicit feature interactions up to degree $d$
RBF / Gaussian$\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)$infinite-dimensional feature space; the default for dense numeric data
Sigmoid$\tanh(\kappa\langle\mathbf{x},\mathbf{z}\rangle + \theta)$not always positive definite; historically linked to neural nets

Validity requires Mercer's condition: the kernel matrix $K_{ij} = K(\mathbf{x}_i,\mathbf{x}_j)$ must be positive semi-definite for any set of inputs. If it is, the kernel corresponds to a genuine inner product in some feature space.

The two hyperparameters

HyperparameterEffectSymptom when wrong
Box constraint $C$tolerance for misclassificationtoo small → underfits (wide margin, many errors); too large → overfits (narrow margin, brittle)
Kernel width $\gamma$radius of influence of each support vectortoo small → each point becomes its own island; too large → the boundary approaches a linear one

Together they control the non-linearity of the boundary, and they interact: the useful region is a diagonal band in the $(C,\gamma)$ plane, which is why a grid search over both (with cross-validation) is standard practice.

Beyond classification, and limitations

SVMs also do regression (support vector regression, with an $\epsilon$-insensitive tube) and anomaly detection (one-class SVM, which encloses the data in a small region of feature space). Their weaknesses are practical:

  • Sensitive to non-uniform feature scaling — always standardise.
  • Cannot handle non-numeric data without an explicit kernel.
  • Training is $O(N^2)$–$O(N^3)$, so it does not scale out of the box to millions of samples.
  • Highly non-linear kernels produce brittle boundaries with poor calibration.

Real-world examples

2 Mathematical foundations

2.1 The margin width is 2/‖w‖

Derivation — distance from a point to a hyperplane, then the gap between the margins
  1. Take a point $\mathbf{x}_0$ on the boundary $\langle\mathbf{w},\mathbf{x}\rangle + b = 0$ and a point $\mathbf{x}$ on the margin $\langle\mathbf{w},\mathbf{x}\rangle + b = 1$. Their difference is orthogonal to the hyperplane.
  2. Project the difference onto the unit normal $\mathbf{w}/\|\mathbf{w}\|$: $$ d = \frac{\langle\mathbf{w},\mathbf{x}-\mathbf{x}_0\rangle}{\|\mathbf{w}\|} = \frac{\big(\langle\mathbf{w},\mathbf{x}\rangle+b\big) - \big(\langle\mathbf{w},\mathbf{x}_0\rangle+b\big)}{\|\mathbf{w}\|} = \frac{1 - 0}{\|\mathbf{w}\|} = \frac{1}{\|\mathbf{w}\|}. $$
  3. There are two such margins, one on each side, so the total width is $2/\|\mathbf{w}\|$. ∎
  4. Maximising $2/\|\mathbf{w}\|$ is the same as minimising $\|\mathbf{w}\|$, and since the square root is monotone, the same as minimising $\frac12\|\mathbf{w}\|^2$ — which is convex and differentiable. The $\frac12$ makes the derivative $\mathbf{w}$ rather than $2\mathbf{w}$.
  5. The constraint $y_i(\langle\mathbf{w},\mathbf{x}_i\rangle+b)\ge1$ is a compact way to write "correct side and outside the margin" for both classes: for $y_i=+1$ it requires the score to be at least $+1$; for $y_i=-1$ at most $-1$.

2.2 From primal to dual

Derivation — the Lagrangian, stationarity, and the dual objective
  1. Introduce multipliers $\alpha_i \ge 0$ for the margin constraints: $$ \mathcal{L}(\mathbf{w},b,\boldsymbol\alpha) = \frac12\|\mathbf{w}\|^2 - \sum_i\alpha_i\big[y_i(\langle\mathbf{w},\mathbf{x}_i\rangle+b)-1\big]. $$
  2. Stationarity with respect to the primal variables: $$ \frac{\partial\mathcal{L}}{\partial\mathbf{w}} = \mathbf{w} - \sum_i\alpha_iy_i\mathbf{x}_i = 0 \;\Longrightarrow\; \mathbf{w} = \sum_i\alpha_iy_i\mathbf{x}_i, \qquad \frac{\partial\mathcal{L}}{\partial b} = -\sum_i\alpha_iy_i = 0. $$
  3. Substituting back eliminates $\mathbf{w}$ and $b$: $$ \mathcal{L} = \frac12\Big\|\sum_i\alpha_iy_i\mathbf{x}_i\Big\|^2 - \sum_i\alpha_iy_i\Big\langle\sum_j\alpha_jy_j\mathbf{x}_j,\mathbf{x}_i\Big\rangle + \sum_i\alpha_i = \sum_i\alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\langle\mathbf{x}_i,\mathbf{x}_j\rangle. $$
  4. So the dual is to maximise that expression subject to $\alpha_i\ge0$ and $\sum_i\alpha_iy_i = 0$. ∎
  5. KKT conditions. At the optimum: (i) stationarity, as above; (ii) primal feasibility $y_i(\langle\mathbf{w},\mathbf{x}_i\rangle+b)\ge1$; (iii) dual feasibility $\alpha_i\ge0$; (iv) complementary slackness $\alpha_i[y_i(\langle\mathbf{w},\mathbf{x}_i\rangle+b)-1]=0$.
  6. Condition (iv) is the sparsity result: if a point is strictly outside the margin, the bracket is positive, so $\alpha_i$ must be zero. Only margin points — the support vectors — have non-zero multipliers.
  7. Recovering $b$: for any support vector, $y_i(\langle\mathbf{w},\mathbf{x}_i\rangle+b)=1$, so $b = y_i - \langle\mathbf{w},\mathbf{x}_i\rangle$; averaging over all support vectors is numerically safer.

2.3 Soft margin and the box constraint

With slacks, the Lagrangian gains multipliers $\mu_i\ge0$ for $\xi_i\ge0$. Stationarity with respect to $\xi_i$ gives $C - \alpha_i - \mu_i = 0$, and since $\mu_i\ge0$ this forces

$$ 0 \le \alpha_i \le C $$

Hence the name box constraint: each multiplier is confined to a box. Three regimes follow from complementary slackness:

$\alpha_i$Position of the pointRole
$0$outside the margin, correctly classifiedignored entirely
$0 \lt \alpha_i \lt C$exactly on the marginsupport vector
$\alpha_i = C$inside the margin or misclassifiedbounded support vector; the slack is active

The dual objective is unchanged in form; only the constraint set changed from $\alpha_i\ge0$ to $0\le\alpha_i\le C$. A larger $C$ allows larger multipliers, which means individual points can pull harder on the boundary.

2.4 Kernels and Mercer's condition

A function $K:\mathcal{X}\times\mathcal{X}\to\mathbb{R}$ is a valid kernel if there exists a feature map $\phi$ with $K(\mathbf{x},\mathbf{z}) = \langle\phi(\mathbf{x}),\phi(\mathbf{z})\rangle$. Mercer's theorem makes this checkable without constructing $\phi$: $K$ is valid iff for every finite set $\{\mathbf{x}_1,\dots,\mathbf{x}_n\}$ the Gram matrix $G_{ij} = K(\mathbf{x}_i,\mathbf{x}_j)$ is positive semi-definite.

Worked example — the RBF kernel corresponds to an infinite-dimensional feature space
  1. Expand $\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2) = \exp(-\gamma\|\mathbf{x}\|^2)\exp(-\gamma\|\mathbf{z}\|^2)\exp(2\gamma\langle\mathbf{x},\mathbf{z}\rangle)$.
  2. Expand the last factor as a power series: $$ \exp(2\gamma\langle\mathbf{x},\mathbf{z}\rangle) = \sum_{k=0}^{\infty}\frac{(2\gamma)^k}{k!}\langle\mathbf{x},\mathbf{z}\rangle^k. $$
  3. Each $\langle\mathbf{x},\mathbf{z}\rangle^k$ is an inner product in the space of degree-$k$ monomials, so the whole expansion is an inner product in the direct sum of all degrees — an infinite-dimensional space. ∎
  4. The kernel never materialises that space: computing $K(\mathbf{x},\mathbf{z})$ costs one squared distance. This is the entire value of the kernel trick, and why the RBF kernel can produce boundaries of arbitrary complexity.
  5. The role of $\gamma$ is now clear: it is the inverse of the length scale over which the kernel considers two points similar. Small $\gamma$ → long-range influence → nearly linear boundaries. Large $\gamma$ → each point only "sees" its immediate neighbourhood → islands around every support vector.

2.5 The hinge loss view

The soft-margin problem can be rewritten as unconstrained regularised loss minimisation:

$$ \min_{\mathbf{w},b}\;\frac12\|\mathbf{w}\|^2 + C\sum_i\max\big(0,\;1 - y_i(\langle\mathbf{w},\mathbf{x}_i\rangle+b)\big) $$

The second term is the hinge loss: zero once a point is correctly classified and outside the margin, and growing linearly with the violation otherwise. Compare with logistic loss, which never reaches exactly zero — that is why SVMs produce sparse solutions (points beyond the margin contribute nothing) while logistic regression uses every point. Both are convex surrogates for the 0/1 loss; neither is the 0/1 loss itself, which is what we would actually like to minimise but cannot optimise directly.

Lab 2 · kernels

The kernel trick, and what γ does

Concentric rings: no straight line separates them, so the linear kernel (switch to it) fails no matter how it is oriented. The RBF kernel succeeds without ever computing a feature map — the Gram matrix replaces every inner product.

Now sweep $\gamma$. At $\gamma \approx 0.2$ the boundary is almost linear and underfits. Around $\gamma \approx 1$ it is a clean annulus. At $\gamma = 6$ the boundary fragments into islands around individual support vectors — the classic overfitting regime. Note also how the support-vector count grows with $\gamma$: more of the data is needed to describe a wigglier boundary.

4 Coding from scratch

"""Module 14 — margin geometry, hinge loss, and a kernel perceptron."""
import math


def dot(a, b):
    return sum(x * y for x, y in zip(a, b))


def margin_width(w):
    return 2.0 / math.sqrt(dot(w, w))


def violations(X, y, w, b):
    return sum(1 for xi, yi in zip(X, y) if yi * (dot(w, xi) + b) < 1)


def hinge_loss(X, y, w, b, C=1.0):
    reg = 0.5 * dot(w, w)
    loss = sum(max(0.0, 1 - yi * (dot(w, xi) + b)) for xi, yi in zip(X, y))
    return reg + C * loss


def svm_sgd(X, y, C=1.0, lr=0.01, epochs=2000):
    """Subgradient descent on the soft-margin objective (the hinge-loss form)."""
    d = len(X[0])
    w, b = [0.0] * d, 0.0
    n = len(X)
    for _ in range(epochs):
        for xi, yi in zip(X, y):
            if yi * (dot(w, xi) + b) < 1:
                # subgradient of the hinge term is active
                w = [wj - lr * (wj - C * yi * xij) for wj, xij in zip(w, xi)]
                b -= lr * (-C * yi)
            else:
                w = [wj - lr * wj for wj in w]
    return w, b


def rbf(a, b, gamma=1.0):
    return math.exp(-gamma * sum((ai - bi) ** 2 for ai, bi in zip(a, b)))


def kernel_perceptron(X, y, gamma=1.0, epochs=30):
    """Dual-form perceptron: only inner products are needed, so any kernel works."""
    n = len(X)
    alpha = [0.0] * n
    for _ in range(epochs):
        errors = 0
        for i in range(n):
            f = sum(alpha[j] * y[j] * rbf(X[j], X[i], gamma) for j in range(n))
            if (1 if f >= 0 else -1) != y[i]:
                alpha[i] += 1
                errors += 1
        if errors == 0:
            break
    return alpha


def kernel_predict(X, y, alpha, x, gamma=1.0):
    return sum(alpha[j] * y[j] * rbf(X[j], x, gamma) for j in range(len(X)))


if __name__ == "__main__":
    w = [1.0, 2.0]
    print("margin width for w=(1,2):", round(margin_width(w), 4))     # 2/sqrt(5)

    X = [[2, 2], [2, 3], [-2, -1], [-2, -2]]
    y = [1, 1, -1, -1]
    w_s, b_s = svm_sgd(X, y, C=1.0, lr=0.01, epochs=400)
    print("learned w:", [round(v, 3) for v in w_s], " b:", round(b_s, 3))
    print("violations:", violations(X, y, w_s, b_s), " hinge loss:", round(hinge_loss(X, y, w_s, b_s), 3))

    # Non-linearly separable: concentric rings
    Xr = [[math.cos(t) * r, math.sin(t) * r]
          for r in (0.5, 1.5) for t in [i * 2 * math.pi / 12 for i in range(12)]]
    yr = [1] * 12 + [-1] * 12
    alpha = kernel_perceptron(Xr, yr, gamma=2.0)
    acc = sum(1 for xi, yi in zip(Xr, yr) if (1 if kernel_predict(Xr, yr, alpha, xi, 2.0) >= 0 else -1) == yi) / len(yr)
    print("rbf kernel perceptron accuracy on rings:", round(acc, 3))

"""Module 14 — vectorised hinge-loss SVM, kernel matrices, and the dual objective."""
import numpy as np


def rbf_kernel(X, Z, gamma=1.0):
    """(n, m) Gram matrix via the expanded squared distance."""
    d2 = (X ** 2).sum(1)[:, None] - 2 * X @ Z.T + (Z ** 2).sum(1)[None, :]
    return np.exp(-gamma * np.clip(d2, 0, None))


def poly_kernel(X, Z, degree=3, c=1.0):
    return (X @ Z.T + c) ** degree


def svm_hinge_sgd(X, y, C=1.0, lr=1e-2, epochs=3000, seed=0):
    """Subgradient descent on 0.5||w||^2 + C * sum hinge."""
    X = np.asarray(X, float)
    y = np.asarray(y, float)
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    rng = np.random.default_rng(seed)
    for epoch in range(epochs):
        order = rng.permutation(n)
        for i in order:
            margin = y[i] * (X[i] @ w + b)
            if margin < 1:
                w -= lr * (w - C * y[i] * X[i])
                b += lr * C * y[i]
            else:
                w -= lr * w
    return w, b


def decision_function(X, w, b):
    return X @ w + b


def dual_objective(K, y, alpha):
    """The quantity maximised by the SVM dual."""
    return alpha.sum() - 0.5 * (alpha * y) @ K @ (alpha * y)


def is_psd(K, tol=1e-8):
    """Mercer check: all eigenvalues non-negative."""
    return bool(np.min(np.linalg.eigvalsh(K)) >= -tol)


def kernel_matrix_checks(X, gamma=1.0):
    K = rbf_kernel(X, X, gamma)
    return {"symmetric": bool(np.allclose(K, K.T)),
            "psd": is_psd(K),
            "diagonal_ones": bool(np.allclose(np.diag(K), 1.0))}


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    X = np.vstack([rng.normal(1.0, 0.7, (50, 2)), rng.normal(-1.0, 0.7, (50, 2))])
    y = np.array([1] * 50 + [-1] * 50, float)

    w, b = svm_hinge_sgd(X, y, C=1.0, lr=0.01, epochs=600)
    print("accuracy:", round(float(((decision_function(X, w, b) > 0) == (y > 0)).mean()), 3))
    print("margin width 2/||w||:", round(2 / np.linalg.norm(w), 3))

    print("RBF kernel checks:", kernel_matrix_checks(X[:20], gamma=0.5))

    # Kernel vs. explicit feature map: the polynomial kernel in 2-D
    x1, x2 = np.array([[1.0, 2.0]]), np.array([[3.0, -1.0]])
    phi = lambda v: np.array([v[0]**2, np.sqrt(2) * v[0] * v[1], v[1]**2])
    print("poly kernel        :", float(poly_kernel(x1, x2, 2)[0, 0]))
    print("explicit phi inner :", float(phi(x1[0]) @ phi(x2[0])))   # identical

"""Module 14 — scikit-learn SVMs: kernels, C/gamma tuning, support vectors."""
import numpy as np
from sklearn.datasets import make_circles, load_breast_cancer
from sklearn.model_selection import GridSearchCV, StratifiedKFold, train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC, SVR, OneClassSVM

# ---- the rings dataset -----------------------------------------------------
X, y = make_circles(n_samples=400, noise=0.08, factor=0.4, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)

for kernel in ("linear", "rbf"):
    m = make_pipeline(StandardScaler(), SVC(kernel=kernel, C=1.0, gamma="scale")).fit(X_tr, y_tr)
    print(f"{kernel:7s} test accuracy: {m.score(X_te, y_te):.3f}  support vectors: {m[-1].n_support_.sum()}")

# ---- C and gamma interact: search the diagonal band -----------------------
cv = StratifiedKFold(5, shuffle=True, random_state=0)
grid = {"svc__C": [0.1, 1, 10, 100], "svc__gamma": [0.01, 0.1, 1, 10]}
search = GridSearchCV(make_pipeline(StandardScaler(), SVC(kernel="rbf")), grid, cv=cv, scoring="accuracy")
search.fit(X_tr, y_tr)
print("\nbest (C, gamma):", search.best_params_, " CV accuracy:", round(search.best_score_, 3))
print("grid:")
for c in grid["svc__C"]:
    row = []
    for g in grid["svc__gamma"]:
        idx = np.where((search.cv_results_["param_svc__C"] == c) &
                       (search.cv_results_["param_svc__gamma"] == g))[0][0]
        row.append(f"{search.cv_results_['mean_test_score'][idx]:.2f}")
    print(f"  C={c:5}: " + "  ".join(row))

# ---- a real dataset, and the effect of scaling ---------------------------
Xb, yb = load_breast_cancer(return_X_y=True)
Xb_tr, Xb_te, yb_tr, yb_te = train_test_split(Xb, yb, test_size=0.2, stratify=yb, random_state=0)
scaled = make_pipeline(StandardScaler(), SVC(kernel="rbf", C=10, gamma="scale")).fit(Xb_tr, yb_tr)
raw = SVC(kernel="rbf", C=10, gamma="scale").fit(Xb_tr, yb_tr)
print(f"\nbreast cancer  scaled: {scaled.score(Xb_te, yb_te):.3f}   unscaled: {raw.score(Xb_te, yb_te):.3f}")

# ---- support vectors are a small fraction of the data -------------------
sv = scaled[-1]
print(f"support vectors: {sv.n_support_.sum()} of {len(Xb_tr)} training points")
print("dual coefficients at the box constraint:", int((np.abs(sv.dual_coef_) >= 10 - 1e-6).sum()))

# ---- SVM beyond classification -----------------------------------------
print("\nSVR on a 1-D regression:", round(float(SVR(kernel="rbf").fit(np.arange(20)[:, None], np.sin(np.arange(20) / 3)).predict([[5.0]])[0]), 3))
print("one-class SVM outliers:", int((OneClassSVM(nu=0.05).fit(Xb_tr).predict(Xb_te) == -1).sum()))
The NumPy block verifies the kernel-trick identity numerically: the polynomial kernel of degree 2 evaluated on two points equals the explicit inner product of their degree-2 feature maps. That equality, generalised to infinite dimensions, is what makes the RBF kernel work.

Q1

For the hyperplane $\mathbf{w}^\top\mathbf{x}+b=0$, the margin width between $\mathbf{w}^\top\mathbf{x}+b=\pm1$ is:

The distance from the boundary to one margin is $1/\|\mathbf{w}\|$, and there are two margins — hence $2/\|\mathbf{w}\|$. Maximising it means minimising $\|\mathbf{w}\|$.

Q2

Why are only the support vectors needed to define the SVM decision boundary?

$\alpha_i[y_i(\mathbf{w}^\top\mathbf{x}_i+b)-1]=0$: if the bracket is positive (outside the margin), $\alpha_i$ must vanish, so those points contribute nothing to $\mathbf{w}=\sum_i\alpha_iy_i\mathbf{x}_i$.

Q3

Increasing the box constraint $C$ in a soft-margin SVM:

$C$ trades margin width against tolerated slack. Small $C$ behaves like strong regularization; large $C$ approaches the hard-margin solution.

Q4

The kernel trick works because:

Replace every $\langle\mathbf{x}_i,\mathbf{x}_j\rangle$ with $K(\mathbf{x}_i,\mathbf{x}_j)$ and you get a non-linear classifier in the input space for the cost of one kernel evaluation per pair.

Q5

A very large $\gamma$ in an RBF kernel produces:

$\gamma$ is an inverse length scale: large $\gamma$ means each point only influences its immediate neighbourhood, so the boundary fragments. Small $\gamma$ gives long-range influence and an almost linear boundary.

Term
Hard-margin primal
Definition
$\min\frac12\|\mathbf{w}\|^2$ s.t. $y_i(\mathbf{w}^\top\mathbf{x}_i+b)\ge1$. Convex quadratic program with a unique optimum when the data is separable.
Term
Support vector
Definition
A training point with $\alpha_i\gt0$, lying on or inside the margin. Only these determine $\mathbf{w}=\sum_i\alpha_iy_i\mathbf{x}_i$.
Term
KKT complementary slackness
Definition
$\alpha_i\times(\text{constraint slack})_i = 0$. Either a constraint is tight or its multiplier is zero — never both non-zero.
Term
Slack variables
Definition
$\xi_i\ge0$ measure how far a point violates the margin; the soft-margin objective charges $C\sum_i\xi_i$ for them.
Term
Hinge loss
Definition
$\max(0, 1-y(\mathbf{w}^\top\mathbf{x}+b))$. Zero beyond the margin, linear inside it — which is why SVM solutions are sparse.
Term
Mercer's condition
Definition
A kernel is valid iff its Gram matrix is positive semi-definite for every finite set of inputs — the checkable form of "it is an inner product in some feature space".
Term
Why standardise for SVMs
Definition
The margin is a Euclidean distance in feature space, so a feature with a large range dominates it. Unscaled inputs can cost tens of accuracy points.
Term
One-class SVM
Definition
Learns a boundary enclosing the training distribution in feature space; points outside are anomalies. Used for novelty detection.

Practice problems

Easy

Margin arithmetic

For $\mathbf{w}=(3,4)$ and $b=-6$: compute $\|\mathbf{w}\|$, the margin width, and the signed distance of the point $(2,2)$ from the boundary.

$\|\mathbf{w}\| = \sqrt{9+16} = 5$, so the margin width is $2/5 = 0.4$.

$\mathbf{w}^\top\mathbf{x}+b = 3(2)+4(2)-6 = 8$. The signed distance is $8/\|\mathbf{w}\| = 1.6$, so the point is outside the positive margin (which sits at distance 0.2).

Medium

Derive the dual

Starting from $\min\frac12\|\mathbf{w}\|^2$ s.t. $y_i(\mathbf{w}^\top\mathbf{x}_i+b)\ge1$, derive the Lagrangian dual and show that $\mathbf{w}=\sum_i\alpha_iy_i\mathbf{x}_i$.

  1. $\mathcal{L} = \frac12\|\mathbf{w}\|^2 - \sum_i\alpha_i[y_i(\mathbf{w}^\top\mathbf{x}_i+b)-1]$ with $\alpha_i\ge0$.
  2. $\partial\mathcal{L}/\partial\mathbf{w} = \mathbf{w}-\sum_i\alpha_iy_i\mathbf{x}_i = 0 \Rightarrow \mathbf{w}=\sum_i\alpha_iy_i\mathbf{x}_i$.
  3. $\partial\mathcal{L}/\partial b = -\sum_i\alpha_iy_i = 0 \Rightarrow \sum_i\alpha_iy_i = 0$.
  4. Substituting back gives $\max_{\boldsymbol\alpha}\sum_i\alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\langle\mathbf{x}_i,\mathbf{x}_j\rangle$ subject to $\alpha_i\ge0$, $\sum_i\alpha_iy_i=0$. ∎
  5. The data now appears only inside $\langle\mathbf{x}_i,\mathbf{x}_j\rangle$ — the hook on which the kernel trick hangs.
Hard

Show the RBF kernel's feature space is infinite-dimensional

Expand $K(\mathbf{x},\mathbf{z})=\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)$ as a power series and argue that it corresponds to an inner product in an infinite-dimensional space.

  1. Factor: $K = e^{-\gamma\|\mathbf{x}\|^2}e^{-\gamma\|\mathbf{z}\|^2}e^{2\gamma\langle\mathbf{x},\mathbf{z}\rangle}$.
  2. Expand the third factor: $e^{2\gamma\langle\mathbf{x},\mathbf{z}\rangle} = \sum_{k\ge0}\frac{(2\gamma)^k}{k!}\langle\mathbf{x},\mathbf{z}\rangle^k$.
  3. For each $k$, $\langle\mathbf{x},\mathbf{z}\rangle^k = \langle \mathbf{x}^{\otimes k}, \mathbf{z}^{\otimes k}\rangle$ is an inner product in the space of degree-$k$ symmetric tensors (dimension $\binom{d+k-1}{k}$).
  4. The full kernel is therefore an inner product in the direct sum over all $k$, which has infinitely many dimensions. ∎
  5. Because the sum converges absolutely for all $\mathbf{x},\mathbf{z}$, the kernel is well defined even though the feature vector is not computable — and evaluating it costs one squared distance.
