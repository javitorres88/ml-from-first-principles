Module 06 · Deep learning

Artificial Neural Networks

From the McCulloch–Pitts neuron to the multilayer perceptron: linear layers are affine maps, composition without activations collapses, and one hidden layer is a universal approximator.

📚 Source: Lecture Notes 3 ⏱ 65 min 🧪 3 interactive labs 🐍 3 implementations

◎ Learning objectives

By the end of this module you should be able to:

  • Describe the perceptron update rule and explain why a single perceptron cannot solve XOR.
  • Show algebraically that stacking linear layers without activations is still a single linear layer.
  • Compare ReLU, sigmoid and tanh, and explain the vanishing-gradient problem of saturating activations.
  • State the universal approximation theorem and what it does *not* promise.
  • Choose architecture hyperparameters (width, depth, output activation, loss) for regression and classification.

1 Intuition

From brains to arithmetic

In 1848 the railroad worker Phineas Gage survived an iron rod passing through his brain — and his physician observed specific personality changes afterwards. The case became evidence for cerebral localization: different parts of the brain support different mental functions. But the deeper lesson for computing was different: no single neuron is important. It is the connections, and the circuits they form, that perform tasks.

A biological neuron has dendrites that receive signals, a cell body that fires when enough input arrives, and an axon that propagates the signal. Connectionist models borrow that vocabulary and nothing else:

YearModelWhat it introduced

The perceptron

A perceptron — also called a Threshold Logic Unit (TLU) — computes a weighted sum of continuous inputs and passes it through a step activation:

$$ o_1 = \sigma\!\left(\sum_{i=1}^{d} w_i x_i\right), \qquad \sigma \in \left\{ H(x) = \begin{cases}1 & x \gt 0\\ 0 & x \le 0\end{cases},\;\; \operatorname{sgn}(x)\right\} $$

Training is refreshingly direct. Initialise the weights to zero or at random, then for each training sample update:

$$ w^{\text{next}}_{i,j} = w_{i,j} + \eta\,(o_j - \hat{o}_j)\,x_i $$

where $\eta$ is the learning rate and $(o_j - \hat{o}_j)$ is the error. If the prediction is correct the update is zero; if it is too low the weights move toward the input; if too high, away from it. The perceptron convergence theorem guarantees that this rule finds a separating hyperplane in finite time if one exists.

The XOR problem

A perceptron is a linear classifier: its decision boundary is the hyperplane $w^\top x = 0$. In 1969 Minsky and Papert showed that no such hyperplane separates XOR:

$x_1$$x_2$$y = x_1 \oplus x_2$

The two classes sit on opposite corners of the unit square. Any line that puts (0,1) and (1,0) on one side must also put at least one of (0,0) or (1,1) there. Adding a hidden layer fixes it: the hidden layer changes the representation, mapping the four points into a space where a single line does separate them. Lab 3 shows both spaces side by side, and the right-hand plot is the important one — the network is not drawing a curved boundary, it is re-drawing the data.

Multilayer perceptrons

An MLP extends multiple linear regression by inserting one or more hidden layers. With one hidden layer of five units and a $4$-dimensional input:

$$ H = XW^{(1)} + \mathbf{b}^{(1)}, \qquad O = HW^{(2)} + \mathbf{b}^{(2)} $$

with $X\in\mathbb{R}^{N\times 4}$, $H\in\mathbb{R}^{N\times 5}$, $O\in\mathbb{R}^{N\times 3}$, $W^{(1)}\in\mathbb{R}^{4\times5}$, $W^{(2)}\in\mathbb{R}^{5\times3}$. Information flows input → hidden → output with no feedback, so an MLP is a feed-forward network: a directed acyclic graph. Biases are broadcast across the batch, i.e. $A + \mathbf{b}$ adds $\mathbf{b}$ to every row.

The composition trap

A network is a composition of functions, $f = f_2 \circ f_1$ with $f_1 = XW^{(1)} + B^{(1)}$ and $f_2 = f_1W^{(2)} + B^{(2)}$. Without a non-linearity between them, $$ O = (XW^{(1)} + B^{(1)})W^{(2)} + B^{(2)} = X\underbrace{W^{(1)}W^{(2)}}_{W} + \underbrace{B^{(1)}W^{(2)} + B^{(2)}}_{B}, $$ which is still a single linear model. Depth without activation buys nothing at all — the whole network collapses into one matrix. This is why the activation function is not a detail.

Activation functions

Name$\sigma(x)$RangeDerivativeNotes
ReLU$\max(x,0)$$[0,\infty)$$1$ if $x\gt0$ else $0$default choice; no saturation for $x\gt0$
Sigmoid$(1+e^{-x})^{-1}$$(0,1)$$\sigma(1-\sigma) \le 0.25$historically favoured (biological); saturates
tanh$\frac{e^x - e^{-x}}{e^x + e^{-x}}$$(-1,1)$$1-\tanh^2 \le 1$zero-centred version of sigmoid

The choice affects representation hardly at all (see the universal approximation theorem below) but affects trainability enormously. A sigmoid's derivative is at most $0.25$, so a gradient backpropagated through $L$ such layers is multiplied by at most $0.25^L$ — after ten layers that is $10^{-6}$. This is the vanishing gradient problem, and it is the main reason ReLU displaced sigmoid in hidden layers. The opposite failure, gradients growing without bound, is the exploding gradient problem. ReLU is not differentiable at zero; by convention its derivative there is set to $0$.

Universal approximation

Cybenko (1989) showed that an MLP with a single hidden layer of arbitrary width can represent any continuous real-valued function on a compact domain. Hornik (1991) showed the choice of activation does not affect this capability. Lu et al. (2017) showed the same for fixed width and arbitrary depth. Three cautions:

  • Represent ≠ learn. The theorem says a good set of weights exists; it says nothing about whether gradient descent will find it, how much data is needed, or how well the network generalizes.
  • Width is unbounded in the theorem. The guarantee is asymptotic, and the required width can be astronomical.
  • Differentiability is needed for training, which is a separate requirement from representability.

2 Mathematical foundations

2.1 Layers as affine maps, networks as compositions

A layer is an affine map $f_\ell(\mathbf{h}) = \sigma_\ell(W^{(\ell)}\mathbf{h} + \mathbf{b}^{(\ell)})$. Stacking $L$ layers gives

$$ f(\mathbf{x}) = f_L \circ f_{L-1} \circ \cdots \circ f_1(\mathbf{x}) $$

and each $W^{(\ell)}\in\mathbb{R}^{n_\ell\times n_{\ell-1}}$. Counting parameters for a 4→5→3 network: $W^{(1)}$ has $4\cdot5=20$, $\mathbf{b}^{(1)}$ has $5$, $W^{(2)}$ has $5\cdot3=15$, $\mathbf{b}^{(2)}$ has $3$: 43 total.

Proof — without a non-linearity, depth collapses to a single layer
  1. Two linear layers: $f_1(\mathbf{x}) = W^{(1)}\mathbf{x} + \mathbf{b}^{(1)}$ and $f_2(\mathbf{h}) = W^{(2)}\mathbf{h} + \mathbf{b}^{(2)}$.
  2. Compose: $$ f_2(f_1(\mathbf{x})) = W^{(2)}\big(W^{(1)}\mathbf{x} + \mathbf{b}^{(1)}\big) + \mathbf{b}^{(2)} = \big(W^{(2)}W^{(1)}\big)\mathbf{x} + \big(W^{(2)}\mathbf{b}^{(1)} + \mathbf{b}^{(2)}\big). $$
  3. Define $W = W^{(2)}W^{(1)}$ and $\mathbf{b} = W^{(2)}\mathbf{b}^{(1)} + \mathbf{b}^{(2)}$. Then $f(\mathbf{x}) = W\mathbf{x} + \mathbf{b}$ — a single affine map. By induction the same holds for any depth. ∎
  4. Consequence: the set of functions representable by a stack of linear layers is exactly the set representable by one linear layer. Non-linearity is what expands the hypothesis class.

2.2 Why the perceptron rule works (when it can)

Sketch — the perceptron convergence theorem
  1. Assume the data is linearly separable with margin $\gamma \gt 0$: there exists $\mathbf{w}^\*$ with $\|\mathbf{w}^\*\|=1$ and $y_i(\mathbf{w}^{*\top}\mathbf{x}_i) \ge \gamma$ for all $i$, where $y_i \in \{-1,+1\}$.
  2. Each update happens only on a mistake, so $\mathbf{w}_{t+1} = \mathbf{w}_t + y_i\mathbf{x}_i$ with $y_i\mathbf{w}_t^\top\mathbf{x}_i \le 0$.
  3. Lower bound on progress: $\mathbf{w}^\*{}^\top\mathbf{w}_{t+1} = \mathbf{w}^{*\top}\mathbf{w}_t + y_i\mathbf{w}^{*\top}\mathbf{x}_i \ge \mathbf{w}^{*\top}\mathbf{w}_t + \gamma$, so after $M$ mistakes $\mathbf{w}^{*\top}\mathbf{w}_M \ge M\gamma$.
  4. Upper bound on growth: $\|\mathbf{w}_{t+1}\|^2 = \|\mathbf{w}_t\|^2 + 2y_i\mathbf{w}_t^\top\mathbf{x}_i + \|\mathbf{x}_i\|^2 \le \|\mathbf{w}_t\|^2 + R^2$ where $R = \max_i\|\mathbf{x}_i\|$, so $\|\mathbf{w}_M\| \le R\sqrt{M}$.
  5. Combine with Cauchy–Schwarz, $\mathbf{w}^{*\top}\mathbf{w}_M \le \|\mathbf{w}_M\|$: $$ M\gamma \le R\sqrt{M} \;\Longrightarrow\; M \le \left(\frac{R}{\gamma}\right)^2. $$
  6. ∎ The number of mistakes is finite and bounded by $(R/\gamma)^2$ — the margin controls the difficulty. If the data is not separable, $\gamma = 0$ and the bound is vacuous: the algorithm never converges.

2.3 Why sigmoid depth destroys gradients

Derivation — the gradient is a product of Jacobians
  1. By the multivariate chain rule, the gradient of the loss with respect to the first layer's weights is $$ \frac{\partial L}{\partial W^{(1)}} = \frac{\partial L}{\partial \mathbf{h}_L}\cdot\frac{\partial \mathbf{h}_L}{\partial \mathbf{h}_{L-1}}\cdots\frac{\partial \mathbf{h}_2}{\partial \mathbf{h}_1}\cdot\frac{\partial \mathbf{h}_1}{\partial W^{(1)}}. $$
  2. For element-wise activations, each factor $\frac{\partial \mathbf{h}_{\ell+1}}{\partial \mathbf{h}_\ell}$ has the form $\mathrm{diag}\big(\sigma'(\mathbf{z}_\ell)\big)W^{(\ell)}$, so its norm is bounded by $\max|\sigma'|\cdot\|W^{(\ell)}\|$.
  3. For the sigmoid, $\max|\sigma'| = 0.25$; for tanh, $1$; for ReLU, $1$ (on the active half). Hence $$ \left\|\frac{\partial L}{\partial W^{(1)}}\right\| \le \left\|\frac{\partial L}{\partial \mathbf{h}_L}\right\|\prod_{\ell=1}^{L-1}\big(0.25\,\|W^{(\ell)}\|\big). $$
  4. If $\|W^{(\ell)}\| \approx 1$, the product decays like $0.25^L$: vanishing. If $\|W^{(\ell)}\| \gt 4$, it grows like $(0.25\|W\|)^L$: exploding. ∎
  5. ReLU keeps the factor at 1 for active units, so the product neither shrinks nor grows systematically. Module 07 fixes the remaining issues with careful initialisation, normalisation, residual connections and adaptive optimisers.

2.4 What the universal approximation theorem actually says

Cybenko's theorem: let $\sigma$ be a continuous, bounded, non-constant activation. Then the set of functions of the form

$$ g(\mathbf{x}) = \sum_{j=1}^{M} \alpha_j\,\sigma\big(\mathbf{w}_j^\top\mathbf{x} + b_j\big) $$

is dense in $C([0,1]^d)$ with respect to the supremum norm: for every continuous $f$ and every $\epsilon \gt 0$ there exist $M$ and parameters with $\sup_{\mathbf{x}}|f(\mathbf{x}) - g(\mathbf{x})| \lt \epsilon$.

Reading the quantifiers carefully

"Dense" is an existence statement over parameters, and $M$ is not bounded. The theorem therefore explains why neural networks are worth trying but not why they work in practice — that is a question about optimisation, data, and inductive bias, and it is still an active research topic.

2.5 A note on initialisation

If all weights start at zero, every hidden unit computes the same thing and receives the same gradient — symmetry is never broken and the network behaves like a single neuron. Small random initialisation breaks the symmetry, but the scale matters: too small and activations shrink layer by layer; too large and they saturate. Module 07 derives the Xavier/He scaling rules that keep variance constant across layers.

Lab 2 · activations

Activation, derivative, and depth

Drag the vertical cursor to choose a pre-activation value $x$. The lower plot shows what happens to a gradient as it is multiplied by $\sigma'(x)$ once per layer.

With the sigmoid and $x=1.2$, the per-layer factor is about $0.18$: after twelve layers the gradient has shrunk by $10^{-9}$ — the first layers learn essentially nothing. Move to $x=0$ and it is $0.25$ per layer, still catastrophic. Switch to ReLU: the factor is either 1 or 0, so depth costs nothing (at the price of dead units). This is the single most important practical fact in this module.

Lab 3 · hidden layers

XOR, solved by a change of representation

Left: the input space, with the four XOR points. No straight line can separate them — Minsky and Papert's point. Right: the same four points plotted in the hidden layer's coordinates $(h_1,h_2)$, where a single line now separates the classes.

Press Train. The network is not learning a curved boundary; it is learning a re-representation in which the problem becomes linear. Set the hidden units to 1 and train again: it can never solve XOR, because one hidden unit gives a one-dimensional representation. Two is the minimum, and that is exactly the classic 2-2-1 solution.

4 Coding from scratch

"""Module 06 — perceptron and a tiny MLP from scratch (forward pass + perceptron rule)."""
import random


def step(x):
    return 1 if x > 0 else 0


def sign(x):
    return 1 if x > 0 else (-1 if x < 0 else 0)


class Perceptron:
    """Rosenblatt's 1957 rule: w += eta * (o - o_hat) * x"""

    def __init__(self, n_features, lr=0.1, seed=0):
        rng = random.Random(seed)
        self.w = [rng.uniform(-0.1, 0.1) for _ in range(n_features)]
        self.b = 0.0
        self.lr = lr

    def predict(self, x):
        return sign(sum(wi * xi for wi, xi in zip(self.w, x)) + self.b)

    def fit(self, X, y, epochs=100):
        for _ in range(epochs):
            errors = 0
            for xi, ti in zip(X, y):
                o = self.predict(xi)
                if o != ti:
                    self.w = [wj + self.lr * (ti - o) * xj for wj, xj in zip(self.w, xi)]
                    self.b += self.lr * (ti - o)
                    errors += 1
            if errors == 0:
                break
        return self


class MLP:
    """One hidden layer, tanh, sigmoid output; forward pass + gradients by hand."""

    def __init__(self, n_in, n_hidden, seed=0):
        rng = random.Random(seed)
        self.W1 = [[rng.gauss(0, 1) for _ in range(n_in)] for _ in range(n_hidden)]
        self.b1 = [0.0] * n_hidden
        self.W2 = [rng.gauss(0, 1) for _ in range(n_hidden)]
        self.b2 = 0.0

    def forward(self, x):
        h = []
        for row, bj in zip(self.W1, self.b1):
            z = sum(w * xi for w, xi in zip(row, x)) + bj
            h.append((z, (2.0 / (1 + pow(2.718281828, -2 * z))) - 1))  # tanh
        z2 = sum(w * hv for w, (_, hv) in zip(self.W2, h)) + self.b2
        p = 1.0 / (1.0 + pow(2.718281828, -z2))
        return h, z2, p

    def fit(self, X, y, epochs=2000, lr=0.5):
        for _ in range(epochs):
            for xi, ti in zip(X, y):
                h, z2, p = self.forward(xi)
                dz = p - ti                                   # dL/dz2 for BCE + sigmoid
                dW2 = [dz * hv for _, hv in h]
                dpre = [dz * w * (1 - hv * hv) for w, (_, hv) in zip(self.W2, h)]
                self.W2 = [w - lr * g for w, g in zip(self.W2, dW2)]
                self.b2 -= lr * dz
                self.W1 = [[w - lr * g * xj for w, xj in zip(row, xi)] for row, g in zip(self.W1, dpre)]
                self.b1 = [b - lr * g for b, g in zip(self.b1, dpre)]
        return self

    def predict(self, x):
        return 1 if self.forward(x)[2] >= 0.5 else 0


if __name__ == "__main__":
    X = [[0, 0], [0, 1], [1, 0], [1, 1]]
    xor = [0, 1, 1, 0]

    p = Perceptron(2).fit(X, [1 if v else -1 for v in xor], epochs=50)
    print("perceptron on XOR:", [p.predict(x) for x in X], "<- fails")

    mlp = MLP(2, 4, seed=3).fit(X, xor, epochs=4000)
    print("MLP on XOR:       ", [mlp.predict(x) for x in X], "<- succeeds")

"""Module 06 — an MLP in NumPy: layers, activations, forward pass, param counts."""
import numpy as np

ACTIVATIONS = {
    "relu": (lambda z: np.maximum(z, 0), lambda z: (z > 0).astype(float)),
    "tanh": (np.tanh, lambda z: 1 - np.tanh(z) ** 2),
    "sigmoid": (lambda z: 1 / (1 + np.exp(-z)), lambda z: (1 / (1 + np.exp(-z))) * (1 - 1 / (1 + np.exp(-z)))),
    "linear": (lambda z: z, lambda z: np.ones_like(z)),
}


def init_layer(n_in, n_out, scheme="he", rng=None):
    rng = rng or np.random.default_rng(0)
    if scheme == "he":            # good for ReLU
        std = np.sqrt(2.0 / n_in)
    elif scheme == "xavier":      # good for tanh / sigmoid
        std = np.sqrt(1.0 / n_in)
    else:                          # the classic mistake
        std = 0.01
    return rng.normal(0, std, (n_in, n_out)), np.zeros(n_out)


def forward(X, params, act="relu", out_act="sigmoid"):
    """params = [(W1,b1), (W2,b2), ...]; returns output and the cache for backprop."""
    cache = []
    A = np.asarray(X, float)
    for i, (W, b) in enumerate(params):
        Z = A @ W + b
        last = i == len(params) - 1
        f = ACTIVATIONS[out_act if last else act][0]
        A = f(Z)
        cache.append((Z, A))
    return A, cache


def count_parameters(params):
    return sum(W.size + b.size for W, b in params)


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    X = rng.normal(size=(8, 4))
    params = [init_layer(4, 5, "he", rng), init_layer(5, 3, "he", rng)]

    out, _ = forward(X, params, act="relu", out_act="linear")
    print("output shape:", out.shape)                     # (8, 3)
    print("parameters  :", count_parameters(params))       # 4*5+5 + 5*3+3 = 43

    # The composition trap: two linear layers = one linear layer.
    W1, b1 = init_layer(4, 5, "xavier", rng)
    W2, b2 = init_layer(5, 3, "xavier", rng)
    linear_two, _ = forward(X, [(W1, b1), (W2, b2)], act="linear", out_act="linear")
    linear_one, _ = forward(X, [(W1 @ W2, b1 @ W2 + b2)], act="linear", out_act="linear")
    print("max difference:", np.abs(linear_two - linear_one).max())   # ~1e-16

    # Activation ranges on a wide input
    z = np.array([[-5.0, -1.0, 0.0, 1.0, 5.0]])
    for name in ("relu", "tanh", "sigmoid"):
        f, d = ACTIVATIONS[name]
        print(f"{name:8s} f={np.round(f(z), 3)}  f'={np.round(d(z), 3)}")

"""Module 06 — the production baseline: MLPClassifier on tabular data."""
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
from sklearn.model_selection import GridSearchCV, StratifiedKFold, train_test_split
from sklearn.neural_network import MLPClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, stratify=y, random_state=0)

# Scaling matters more for neural nets than for trees: it conditions the optimisation.
mlp = make_pipeline(
    StandardScaler(),
    MLPClassifier(
        hidden_layer_sizes=(32, 16),   # two hidden layers
        activation="relu",
        solver="adam",
        alpha=1e-3,                    # L2 penalty
        learning_rate_init=1e-3,
        max_iter=2000,
        early_stopping=True,           # holds out 10% for validation
        random_state=0,
    ),
)
mlp.fit(X_tr, y_tr)
print("test accuracy:", round(mlp.score(X_te, y_te), 4))
print("epochs run   :", mlp[-1].n_iter_)
print("loss curve   :", [round(v, 3) for v in mlp[-1].loss_curve_[:5]], "...")

# Architecture search: width and depth vs. performance
cv = StratifiedKFold(5, shuffle=True, random_state=0)
grid = {
    "mlpclassifier__hidden_layer_sizes": [(16,), (64,), (32, 16), (64, 32, 16)],
    "mlpclassifier__alpha": [1e-4, 1e-2],
}
search = GridSearchCV(mlp, grid, cv=cv, scoring="roc_auc", n_jobs=-1)
search.fit(X_tr, y_tr)
print("\nbest architecture:", search.best_params_)
print("best CV AUC      :", round(search.best_score_, 4))

# Compare against logistic regression: on small tabular data the gap is often small.
lr = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)).fit(X_tr, y_tr)
print("logistic AUC     :", round(roc_auc_score(y_te, lr.predict_proba(X_te)[:, 1]), 4))
print("MLP AUC          :", round(roc_auc_score(y_te, mlp.predict_proba(X_te)[:, 1]), 4))
The NumPy block proves the composition trap numerically: a two-linear-layer network and its collapsed single-layer equivalent agree to machine precision. That is why act="relu" is not optional.

5 Assessment

Quiz

Q1

A network has 4 inputs, one hidden layer of 5 units, and 3 outputs, all fully connected. How many parameters (weights + biases)?

$4\cdot5+5 = 25$ for layer 1, $5\cdot3+3 = 18$ for layer 2, total 43.

Q2

What happens if you stack five linear layers with no activation functions?

$(W_5\cdots W_1)\mathbf{x} + \mathbf{b}'$ — a product of matrices is a matrix. Non-linearity is what expands the hypothesis class.

Q3

Why is a single perceptron unable to learn XOR?

The classes sit on opposite corners of the unit square; every line fails on at least one point. A hidden layer re-represents the data so that it becomes separable.

Q4

A gradient is backpropagated through 12 sigmoid layers, each with $\sigma'(z)\approx0.2$. What is the effect on the first layer's gradient?

Gradients compose multiplicatively through layers, so a per-layer factor below 1 compounds exponentially — the vanishing-gradient problem. ReLU keeps the factor at 1 for active units.

Q5

The universal approximation theorem guarantees that:

It is an existence statement about representability, with unbounded width. It says nothing about optimisation, sample complexity or generalisation.

Feed-forward network
Definition
A directed acyclic graph of layers: information flows input → output with no feedback. MLPs and CNNs are feed-forward; RNNs are not.
Term
Hidden layer
Definition
A layer whose output is not observed. Its job is to re-represent the input so that the final linear layer can solve the task.
Term
ReLU
Definition
$\max(x,0)$. Cheap, non-saturating for positive inputs, derivative 1 or 0. The default hidden activation; derivative at 0 defined as 0.
Term
Vanishing gradient
Definition
Gradients multiplied by factors below 1 at every layer decay exponentially with depth. Caused by saturating activations; fixed by ReLU, normalisation, residual connections and good initialisation.
Term
Exploding gradient
Definition
The same product grows without bound, producing numerical overflow and unstable training. Fixed by gradient clipping (module 11) and careful initialisation.
Term
Universal approximation
Definition
Cybenko (1989): a single hidden layer of arbitrary width can approximate any continuous function on a compact domain to any accuracy. An existence result, not a training guarantee.
Term
Symmetry breaking
Definition
Why weights must be initialised randomly: with all-zero weights every hidden unit computes the same value and receives the same gradient, so the network never differentiates its units.

Medium

Derive the vanishing-gradient bound

For an $L$-hidden-layer network with sigmoid activations and weight matrices of spectral norm at most 1, bound the norm of $\partial L/\partial W^{(1)}$ in terms of the output gradient and $L$.

  1. Each layer contributes $\mathrm{diag}(\sigma'(\mathbf{z}_\ell))W^{(\ell)}$, with spectral norm at most $\max|\sigma'|\cdot\|W^{(\ell)}\|_2 \le 0.25$.
  2. Norms of products are at most the product of norms, so $$ \left\|\frac{\partial L}{\partial W^{(1)}}\right\| \le \left\|\frac{\partial L}{\partial \mathbf{h}_L}\right\|\cdot 0.25^{L-1}. $$
  3. For $L=20$ this is $0.25^{19} \approx 3.6\times10^{-12}$: the first layer's gradient is numerically zero in float32. ∎
  4. The bound is worst-case, but in practice saturating units make it realistic: sigmoid networks deeper than about 5 layers were essentially untrainable before ReLU and normalisation.
Hard

Perceptron convergence bound

Prove that if the data is linearly separable with margin $\gamma$ and all inputs satisfy $\|\mathbf{x}_i\|\le R$, the perceptron makes at most $(R/\gamma)^2$ mistakes.

  1. Normalise so that $\|\mathbf{w}^\*\| = 1$ and $y_i\langle\mathbf{w}^\*,\mathbf{x}_i\rangle \ge \gamma$.
  2. Progress: on each mistake $\langle\mathbf{w}^\*,\mathbf{w}_{t+1}\rangle = \langle\mathbf{w}^\*,\mathbf{w}_t\rangle + y_i\langle\mathbf{w}^\*,\mathbf{x}_i\rangle \ge \langle\mathbf{w}^\*,\mathbf{w}_t\rangle + \gamma$, so after $M$ mistakes $\langle\mathbf{w}^\*,\mathbf{w}_M\rangle \ge M\gamma$.
  3. Growth: $\|\mathbf{w}_{t+1}\|^2 \le \|\mathbf{w}_t\|^2 + \|\mathbf{x}_i\|^2 \le \|\mathbf{w}_t\|^2 + R^2$ (the cross term is non-positive on a mistake), so $\|\mathbf{w}_M\|\le R\sqrt{M}$.
  4. Cauchy–Schwarz: $M\gamma \le \langle\mathbf{w}^\*,\mathbf{w}_M\rangle \le \|\mathbf{w}_M\| \le R\sqrt{M}$, hence $M \le (R/\gamma)^2$. ∎
  5. Interpretation: the bound depends on the margin, not on the dimension — but it grows quadratically as the margin shrinks, which is why nearly-inseparable data is slow.

Project 06

Build an MLP and prove it should exist

Implement a multilayer perceptron from scratch, then use it to answer an experimental question about architecture rather than just to fit a dataset.

Brief

  1. Implement a configurable MLP (any depth/width, ReLU/tanh/sigmoid, MSE or cross-entropy) with manual forward and backward passes.
  2. Verify the backward pass with a numerical gradient check (central differences) — report the maximum relative error.
  3. Reproduce the composition trap: train a 2-layer linear network and a 1-layer linear network on the same data and show identical decision boundaries.
  4. Run a depth sweep (1–6 hidden layers) with sigmoid versus ReLU and plot training loss curves. Explain the difference using the product-of-Jacobians argument.
  5. Fit XOR, then two-moons, then a real tabular dataset; report where the MLP beats logistic regression and where it does not.

Deliverables

  • mlp.py with gradient-checked backward pass
  • Figure: loss curves for sigmoid vs. ReLU at each depth
  • Short report with the composition-trap experiment and the XOR verification table
