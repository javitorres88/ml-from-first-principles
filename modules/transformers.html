Transformers & Large Language Models

Self-attention as soft dictionary lookup: queries, keys, values, the √d_k scaling, multi-head projections, causal masking, sinusoidal positional encoding, and how GPT, BERT and scaling laws fit together.

1 Intuition

What transformers are for

Transformers are a class of neural network architecture built on self-attention, which lets every position in a sequence attend to every other position — capturing long-range dependencies in a single step rather than through a chain of recurrences. They are now the dominant architecture for natural language processing, code generation and chatbot LLMs, they replace CNNs in vision (ViTs), and they enabled scientific results such as AlphaFold.

Module 11 ended with three problems and three fixes: vanishing gradients → residual connections; unstable activations → layer normalisation; state updates → attention. A transformer is exactly that combination, plus one ingredient of its own (positional encoding), because attention on its own is order-blind.

The problem setup

Text is parsed into tokens — semantic units roughly corresponding to words or sub-words. A vocabulary has tens of thousands of tokens, encoded and compressed (for instance with byte-pair encoding) into integers, plus control tokens such as [UNK], [CLS], [SEP]. Each integer indexes an embedding vector, and the sequence of embeddings is what the transformer consumes.

Four components

ComponentRole
Self-attentionlets each position gather information from all positions, with learned weights
Positional encodinginjects information about where each token is, since attention has no inherent order
Residual connectionscarry the signal and the gradient around each sub-layer
Layer normalisationnormalises across the feature dimension (not the batch), stabilising activations

The main body is an encoder–decoder: the encoder processes the input sequence into context-rich representations, and the decoder generates the output sequence one token at a time, using both the encoder's representations (through cross-attention) and its own previous outputs. Each encoder or decoder block is a self-attention layer followed by a feed-forward MLP applied at each token position.

Self-attention as a search engine

The cleanest way to understand attention is as an information-retrieval system. A YouTube search matches your search terms (the query) against the metadata of videos (the keys) and returns the most relevant videos (the values). Self-attention does the same thing inside a sequence: each token issues a query, every token advertises a key, similarity between them decides how much of each value to retrieve.

$$ \mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$
StepComputationMeaning
1. Project$Q = XW_Q$, $K = XW_K$, $V = XW_V$learn three views of the same embeddings
2. Score$QK^\top$compatibility of each query with each key
3. Scale$\div\sqrt{d_k}$keep the softmax in a region with usable gradients
4. Normalise$\mathrm{softmax}(\cdot)$turn scores into a convex combination
5. Aggregate$\times V$weighted sum of value vectors

The canonical demonstration: in "The animal didn't cross the street because it was too tired", the token it attends strongly to animal; in "…because it was too wide", it attends to street. The same weights, different context, different answer — which is exactly what a static embedding cannot do.

Why divide by √d_k?

As the key dimension grows, dot products of roughly independent entries grow in magnitude like $\sqrt{d_k}$ (their variance is $d_k$). Large scores push the softmax into saturation, where one weight is ≈1 and the rest ≈0 — and the gradient of a saturated softmax is nearly zero. Dividing by $\sqrt{d_k}$ restores unit variance and keeps training alive. Lab 1 lets you turn the scaling off and watch the weights collapse onto a single token.

Multi-head attention

A single attention head can only express one notion of relevance. Multi-head attention runs $h$ attention operations in parallel on projected subspaces, then concatenates and projects:

$$ \mathbf{c}_i = \mathrm{attention}\big(QW_Q^{(i)},\, KW_K^{(i)},\, VW_V^{(i)}\big), \qquad \mathrm{MultiHead}(Q,K,V) = \mathrm{concat}(\mathbf{c}_1,\dots,\mathbf{c}_h)W_O $$

Each head can specialise: one tracks syntax, another tracks coreference, another tracks position. This is precisely analogous to using multiple filters in a CNN — several detectors in parallel, combined by a learned projection.

Masking

  • Encoder attention is all-to-all: each token attends to the entire input, including itself.
  • Padding masks ignore the padding used to make sequences equal length.
  • Decoder attention is causal: token $t$ may attend only to tokens $\le t$. The mask is applied by setting future scores to $-\infty$ before the softmax, so their weights become exactly zero. This preserves the autoregressive property — the model can never cheat by looking at the answer it is about to predict.

Positional encoding

Attention is permutation-equivariant: shuffle the tokens and the outputs shuffle with them. Word order is crucial, so position information must be injected. The original transformer adds fixed sinusoids of geometrically spaced frequencies:

$$ \mathrm{PE}_{(\text{pos},\,2i)} = \sin\!\left(\frac{\text{pos}}{10000^{2i/d_{\text{model}}}}\right), \qquad \mathrm{PE}_{(\text{pos},\,2i+1)} = \cos\!\left(\frac{\text{pos}}{10000^{2i/d_{\text{model}}}}\right) $$

Even dimensions use sine, odd dimensions cosine, and the $10000^{2i/d}$ term gives each dimension its own frequency. Low dimensions oscillate quickly (they encode fine position), high dimensions slowly (coarse position). Both sine and cosine are needed: a single sinusoid cannot distinguish $p=22$ from $p=35$ in a high-frequency dimension.

From transformer to LLM

The original transformer was designed for translation and trained supervised, on bilingual corpora. Scaling that up requires ever larger labelled datasets, which do not exist for general language ability. The resolution is self-supervised learning: take a large unlabelled corpus, mask or shift the text, and use the next token as its own label.

Concretely, given "Deep learning on Google CoLab is fab" with $l=7$ tokens: feed "Deep learning" and ask the model to predict "on"; measure the loss, backpropagate; then feed "Deep learning on" and predict "Colab"; and so on, over minibatches. Pretraining is followed by supervised fine-tuning (either feature-based, as in transfer learning, or by fine-tuning the whole model) — the two-step process called semi-supervised learning.

FamilyArchitectureTraining objectiveGood at
GPT (2018–)decoder only, causalnext-token predictiongeneration, in-context learning
BERT (2018)encoder only, bidirectionalmasked language modelling + next-sentence predictionclassification, extraction, QA
BART / T5 (2019)encoder–decoderdenoising / span corruptiontranslation, summarisation

GPT-2 (1.5B parameters) established that a decoder trained on enough text performs many tasks zero-shot, given the task in the context window. GPT-3 (175B) established in-context learning: put a few examples in the prompt and the model infers the task without any weight updates. Both rely on sparse attention, because full self-attention is quadratic in sequence length: with $t$ tokens the weight matrix has $t^2$ entries. Sparse patterns reduce this to sub-quadratic complexity at some cost in expressiveness.

Limits of scaling

Loss falls as a power law in parameters, data and compute — the empirical basis of the "scaling hypothesis". Two hard constraints are emerging: high-quality training text is finite (the projected exhaustion of the public corpus is a measured result, not a guess), and compute cost grows by orders of magnitude per generation. Both are why data efficiency, retrieval and mixture-of-experts architectures are active research areas.

2 Mathematical foundations

2.1 Scaled dot-product attention, worked

For a sequence of $n$ tokens with $Q,K,V\in\mathbb{R}^{n\times d_k}$:

  1. $S = QK^\top\in\mathbb{R}^{n\times n}$: entry $S_{ij} = \mathbf{q}_i\cdot\mathbf{k}_j$.
  2. $S \leftarrow S/\sqrt{d_k}$; optionally set masked entries to $-\infty$.
  3. $A = \mathrm{softmax}_{\text{row}}(S)$: each row is a probability distribution over the $n$ positions.
  4. $H = AV$: row $i$ of $H$ is $\sum_j A_{ij}\mathbf{v}_j$, a convex combination of value vectors.

Total cost: $O(n^2d_k)$ for $QK^\top$ plus $O(n^2d_v)$ for $AV$ — quadratic in sequence length, which is the fundamental scaling limitation.

Derivation — why scores grow like √d_k and why that breaks the softmax
  1. Let the components of $\mathbf{q}$ and $\mathbf{k}$ be independent with mean 0 and variance 1. Then $$ \mathbb{E}[\mathbf{q}\cdot\mathbf{k}] = \sum_{i=1}^{d_k}\mathbb{E}[q_ik_i] = 0, \qquad \mathrm{Var}(\mathbf{q}\cdot\mathbf{k}) = \sum_{i=1}^{d_k}\mathrm{Var}(q_ik_i) = d_k. $$
  2. So the standard deviation of the scores is $\sqrt{d_k}$: with $d_k = 64$, typical scores are around $\pm8$.
  3. Feed scores of that spread into a softmax with $n$ entries and the largest one dominates: $e^{8}$ versus $e^{0}$ is a ratio of about 3,000, so one weight is ≈1 and the rest ≈0.
  4. The softmax Jacobian is $a_i(\delta_{ij}-a_j)$. When $\mathbf{a}$ is one-hot, every entry of that Jacobian is 0 — no gradient reaches the scores, and attention stops learning. ∎
  5. Dividing by $\sqrt{d_k}$ restores unit variance, keeps the softmax in a well-conditioned regime, and is the entire justification for the $\sqrt{d_k}$ in the formula.

2.2 Multi-head attention as a sum of low-rank terms

With $h$ heads of dimension $d_k = d_{\text{model}}/h$, each head computes a rank-$\le d_k$ update to the residual stream. Writing out one head without the final projection,

$$ H^{(i)} = \mathrm{softmax}\!\left(\frac{XW_Q^{(i)}W_K^{(i)\top}X^\top}{\sqrt{d_k}}\right)XW_V^{(i)} $$

so each head is a data-dependent, low-rank linear map of $X$. Concatenating $h$ of them and applying $W_O$ mixes the heads. Two practical consequences: the total parameter count is roughly the same as one head of full width (because $d_k = d/h$), and the rank of the combined update is at most $h\,d_k = d$ — heads do not add capacity so much as diversity of routing.

2.3 Positional encoding and relative offsets

Derivation — the rotation identity behind relative positions
  1. Write the encoding of position $p$ in dimension pair $i$ as a vector $\mathrm{PE}_i(p) = \big(\sin(p\omega_i), \cos(p\omega_i)\big)$ with $\omega_i = 10000^{-2i/d}$.
  2. Apply the angle-addition formulas: $$ \sin\big((p+\Delta)\omega_i\big) = \sin(p\omega_i)\cos(\Delta\omega_i) + \cos(p\omega_i)\sin(\Delta\omega_i), $$ $$ \cos\big((p+\Delta)\omega_i\big) = \cos(p\omega_i)\cos(\Delta\omega_i) - \sin(p\omega_i)\sin(\Delta\omega_i). $$
  3. In matrix form, $\mathrm{PE}_i(p+\Delta) = R(\Delta\omega_i)\,\mathrm{PE}_i(p)$ where $R$ is a rotation by $\Delta\omega_i$ that depends only on the offset $\Delta$, not on $p$. ∎
  4. So a linear function of the encoding can recover relative position — which is why fixed sinusoids work at all, and why the model can generalise to offsets it never saw. Lab 2 shows the cosine similarity between $\mathrm{PE}(p)$ and $\mathrm{PE}(p+\Delta)$ decaying smoothly with $\Delta$, the fingerprint of this structure.
  5. Because different dimensions have different $\omega_i$, the full encoding gives every position a unique vector (absolute position) while simultaneously encoding offsets at multiple scales (relative position).

2.4 Layer normalisation, and why not batch norm

LayerNorm normalises across the feature dimension for each token independently:

$$ \mathrm{LN}(\mathbf{x}) = \gamma\odot\frac{\mathbf{x}-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta, \qquad \mu = \frac1d\sum_i x_i,\quad \sigma^2 = \frac1d\sum_i (x_i-\mu)^2 $$

Batch norm normalises across the batch for each feature. For sequences, batch statistics mix unrelated samples and depend on batch size; layer statistics depend only on the token itself, so they are identical at training and inference and work with batch size 1. Modern transformers use a pre-norm arrangement (normalise before the sub-layer, then add the residual), which trains more stably at depth than the original post-norm.

2.5 Scaling laws, briefly

Empirically, test loss falls as a power law in model size $N$, dataset size $D$ and compute $C$: $L \propto N^{-\alpha_N}$, $L \propto D^{-\alpha_D}$, with exponents around $0.05$–$0.1$. On log–log axes these are straight lines, which is why "make it bigger" worked for a decade. The exponents also imply diminishing returns: each additional order of magnitude of compute buys a fixed fractional reduction in loss, so the cost per unit of improvement grows exponentially. Chinchilla-style results refine this into a practical rule — for a fixed compute budget, parameters and tokens should be scaled together, and most early large models were badly undertrained relative to their size.

3 Interactive visualizations

Lab 1 · self-attention

Score matrix → weight matrix

Five tokens, one attention head. The top matrix is $QK^\top/\sqrt{d_k}$ (red positive, blue negative); the bottom is the row-wise softmax that turns it into weights. Each row sums to exactly 1 — that invariant is printed in the panel.

Now turn off the $\sqrt{d_k}$ scaling and raise the sharpness: the score matrix saturates and the weight matrix collapses onto a single column per row — one-hot attention, zero gradient, no learning. Turn scaling back on and the weights soften. Finally enable the causal mask: the upper triangle becomes exactly zero, which is the autoregressive property that makes GPT-style generation possible.

Lab 2 · positions

Sinusoidal positional encoding

The matrix has one row per position and one column per dimension. Low dimensions oscillate fast (they encode fine position); high dimensions oscillate slowly (coarse position) — the geometric spacing of frequencies is what gives the encoding multiple scales at once.

Change the offset $\Delta$ and watch the similarity readout: $\mathrm{PE}(p)$ and $\mathrm{PE}(p+\Delta)$ are nearly identical for small offsets and decorrelate smoothly as $\Delta$ grows. That decay is the relative-position structure of §2.3, and it is why a linear layer can recover offsets from these features.

4 Coding from scratch

"""Module 12 — scaled dot-product attention and positional encoding, no libraries."""
import math


def matmul(A, B):
    Bt = list(zip(*B))
    return [[sum(a * b for a, b in zip(row, col)) for col in Bt] for row in A]


def transpose(A):
    return [list(r) for r in zip(*A)]


def softmax(row):
    m = max(row)
    e = [math.exp(v - m) for v in row]
    s = sum(e)
    return [v / s for v in e]


def scaled_dot_product_attention(Q, K, V, causal=False):
    """Q,K,V: n x d lists. Returns (output, attention weights)."""
    n, dk = len(Q), len(Q[0])
    scores = matmul(Q, transpose(K))                 # n x n
    for i in range(n):
        for j in range(n):
            scores[i][j] /= math.sqrt(dk)             # the scaling term
            if causal and j > i:
                scores[i][j] = float("-inf")          # mask the future
    weights = [softmax(row) for row in scores]
    out = matmul(weights, V)
    return out, weights


def positional_encoding(max_pos, d_model):
    pe = []
    for pos in range(max_pos):
        row = []
        for i in range(d_model // 2):
            omega = 1.0 / (10000 ** (2 * i / d_model))
            row += [math.sin(pos * omega), math.cos(pos * omega)]
        pe.append(row)
    return pe


def multi_head(Q, K, V, n_heads):
    """Split the feature dimension into heads, attend in each, concatenate."""
    d = len(Q[0])
    dh = d // n_heads
    outs = []
    for h in range(n_heads):
        sl = slice(h * dh, (h + 1) * dh)
        Qh = [row[sl] for row in Q]
        Kh = [row[sl] for row in K]
        Vh = [row[sl] for row in V]
        o, _ = scaled_dot_product_attention(Qh, Kh, Vh)
        outs.append(o)
    return [[v for h in range(n_heads) for v in outs[h][i]] for i in range(len(Q))]

"""Module 12 — vectorised attention, a full transformer block, and causal masking."""
import numpy as np


def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)


def scaled_dot_product_attention(Q, K, V, mask=None):
    dk = Q.shape[-1]
    scores = Q @ K.swapaxes(-1, -2) / np.sqrt(dk)
    if mask is not None:
        scores = np.where(mask, scores, -np.inf)
    weights = softmax(scores, axis=-1)
    return weights @ V, weights


def causal_mask(n):
    return np.tril(np.ones((n, n), dtype=bool))


def positional_encoding(max_pos, d_model):
    pos = np.arange(max_pos)[:, None]
    i = np.arange(0, d_model, 2)[None, :]
    omega = 1.0 / (10000 ** (i / d_model))
    pe = np.zeros((max_pos, d_model))
    pe[:, 0::2] = np.sin(pos * omega)
    pe[:, 1::2] = np.cos(pos * omega)
    return pe


def layer_norm(x, gamma, beta, eps=1e-5):
    mu = x.mean(-1, keepdims=True)
    var = x.var(-1, keepdims=True)
    return gamma * (x - mu) / np.sqrt(var + eps) + beta


def multi_head_attention(X, Wq, Wk, Wv, Wo, n_heads, mask=None):
    n, d = X.shape
    dh = d // n_heads
    Q, K, V = X @ Wq, X @ Wk, X @ Wv
    heads = []
    for h in range(n_heads):
        sl = slice(h * dh, (h + 1) * dh)
        o, _ = scaled_dot_product_attention(Q[:, sl], K[:, sl], V[:, sl], mask)
        heads.append(o)
    return np.concatenate(heads, axis=-1) @ Wo


def transformer_block(X, params, n_heads, mask=None):
    """Pre-norm: LN -> attention -> residual -> LN -> MLP -> residual."""
    p = params
    A = multi_head_attention(layer_norm(X, p["g1"], p["b1"]),
                             p["Wq"], p["Wk"], p["Wv"], p["Wo"], n_heads, mask)
    X = X + A
    H = layer_norm(X, p["g2"], p["b2"])
    X = X + np.maximum(H @ p["W1"] + p["c1"], 0) @ p["W2"] + p["c2"]
    return X

"""Module 12 — the real thing: nn.MultiheadAttention, a small GPT, and a pretrained tokenizer."""
import torch
import torch.nn as nn


class CausalSelfAttention(nn.Module):
    def __init__(self, d_model, n_heads, block_size):
        super().__init__()
        assert d_model % n_heads == 0
        self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.register_buffer("mask", torch.tril(torch.ones(block_size, block_size)).bool())

    def forward(self, x):
        T = x.size(1)
        out, weights = self.attn(x, x, x, attn_mask=self.mask[:T, :T], need_weights=True)
        return out, weights


class Block(nn.Module):
    def __init__(self, d_model, n_heads, block_size, dropout=0.1):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d_model), nn.LayerNorm(d_model)
        self.sa = CausalSelfAttention(d_model, n_heads, block_size)
        self.mlp = nn.Sequential(nn.Linear(d_model, 4 * d_model), nn.GELU(),
                                 nn.Linear(4 * d_model, d_model), nn.Dropout(dropout))

    def forward(self, x):
        a, w = self.sa(self.ln1(x))
        x = x + a                       # residual around attention
        x = x + self.mlp(self.ln2(x))   # residual around the MLP
        return x, w


class TinyGPT(nn.Module):
    def __init__(self, vocab, d_model=64, n_heads=4, n_layers=2, block_size=32):
        super().__init__()
        self.tok = nn.Embedding(vocab, d_model)
        self.pos = nn.Embedding(block_size, d_model)
        self.blocks = nn.ModuleList([Block(d_model, n_heads, block_size) for _ in range(n_layers)])
        self.ln_f = nn.LayerNorm(d_model)
        self.head = nn.Linear(d_model, vocab, bias=False)

    def forward(self, idx):
        T = idx.size(1)
        x = self.tok(idx) + self.pos(torch.arange(T, device=idx.device))
        for b in self.blocks:
            x, _ = b(x)
        return self.head(self.ln_f(x))


if __name__ == "__main__":

    text = "attention is all you need. " * 60
    vocab = sorted(set(text))
    stoi = {c: i for i, c in enumerate(vocab)}
    data = torch.tensor([stoi[c] for c in text])

    model = TinyGPT(len(vocab), block_size=24)
    opt = torch.optim.AdamW(model.parameters(), lr=3e-3)

        opt.zero_grad(); loss.backward()
        nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        opt.step()
        if step % 100 == 0:

    with torch.no_grad():
        for _ in range(40):
            logits = model(idx[:, -24:])
            probs = torch.softmax(logits[:, -1] / 0.8, dim=-1)
            nxt = torch.multinomial(probs, 1)
            idx = torch.cat([idx, nxt], dim=1)
    print("sample:", "".join(vocab[i] for i in idx[0].tolist()))

    # Inspect an attention map: the causal structure must be visible
    _, w = model.blocks[0].sa(model.pos(torch.arange(8)).unsqueeze(0))
    print("attention shape:", tuple(w.shape), " upper-triangle zero:", bool((w[0].triu(1) == 0).all()))
The NumPy block isolates the three ideas: attention with and without the $\sqrt{d_k}$ scaling, the causal mask, and a full pre-norm transformer block. The PyTorch block is a complete (if tiny) GPT: embedding + position + blocks + head, trained on next-token prediction and then sampled autoregressively.

5 Assessment

Quiz

Q1

In $\mathrm{Attention}(Q,K,V) = \mathrm{softmax}(QK^\top/\sqrt{d_k})V$, the division by $\sqrt{d_k}$ exists because:

Scaling restores unit variance, keeps the softmax soft, and preserves a usable gradient. Lab 1 lets you switch it off and watch the weights become one-hot.

Q2

What does the causal mask do in a decoder's self-attention?

After the softmax, $e^{-\infty}=0$, so future positions receive exactly zero weight. Without it, training would leak the answer into the prediction.

Q3

Why is positional encoding necessary?

Attention weights depend on content similarity, not position — shuffle the tokens and the outputs shuffle with them. Adding a position-dependent vector to each embedding breaks that symmetry.

Q4

Which architecture and objective match GPT versus BERT?

GPT generates left-to-right (causal mask), so it is a decoder. BERT sees the whole sequence bidirectionally (no mask) and is trained to fill in blanks, which makes it an encoder.

Q5

Self-attention's cost in sequence length $t$ is:

The attention matrix has $t^2$ entries. Sparse patterns (local windows, strided blocks, global tokens) reduce this to sub-quadratic complexity — one of the enablers of GPT-3.

Flashcards

Click to flip · arrow keys to navigate
Term
Query, key, value
Definition
Three learned projections of the same embeddings: queries ask, keys advertise, values carry content. Attention is a soft dictionary lookup.
Term
Multi-head attention
Definition
$h$ attention operations on projected subspaces of width $d/h$, concatenated and mixed by $W_O$. Different heads specialise in different relations, like multiple CNN filters.
Term
Cross-attention
Definition
Decoder queries attend to encoder keys and values, so each output token can look at the relevant part of the input.
Term
Layer normalisation
Definition
Normalise across the feature dimension per token, then rescale with learned $\gamma,\beta$. Unlike batch norm it works with batch size 1 and behaves identically at train and test time.
Term
Self-supervised learning
Definition
Create labels from the data itself: predict the next token (GPT) or fill in masked tokens (BERT). This is what made training on internet-scale corpora possible.
Term
In-context learning
Definition
Putting a few examples in the prompt so the model infers the task without any weight updates — the behaviour that appeared at GPT-3 scale.
Term
Scaling law
Definition
Loss falls as a power law in parameters, data and compute. Straight lines on log–log plots, with diminishing returns per order of magnitude.
Term
Vision Transformer (ViT)
Definition
Split an image into fixed-size patches, embed each linearly, add position embeddings, and run a standard transformer encoder. Needs large-scale pretraining to beat CNNs.

Practice problems

Easy

Compute one attention row

With $d_k=2$, a query $\mathbf{q}=(1,0)$ and keys $\mathbf{k}_1=(1,0)$, $\mathbf{k}_2=(0,1)$, $\mathbf{k}_3=(1,1)$, compute the attention weights and the resulting output if $\mathbf{v}_1=(10,0)$, $\mathbf{v}_2=(0,10)$, $\mathbf{v}_3=(5,5)$.

Scores: $1,\;0,\;1$; scaled by $\sqrt{2}$: $0.707,\;0,\;0.707$.

Softmax: $e^{0.707}=2.028$, $e^{0}=1$, $e^{0.707}=2.028$; sum $=5.056$. Weights: $0.401,\;0.198,\;0.401$.

Output $= 0.401(10,0) + 0.198(0,10) + 0.401(5,5) = (4.01 + 2.01,\; 1.98 + 2.01) = (6.02,\; 3.99)$.

Note that the output is a convex combination of the values — attention can only blend what is already there.

Medium

Show the scaling keeps the scores at unit variance

Assume $q_i,k_i\sim\mathcal{N}(0,1)$ independent. Show that $\mathrm{Var}(\mathbf{q}\cdot\mathbf{k}) = d_k$ and that dividing by $\sqrt{d_k}$ makes the variance 1. Estimate the largest of 100 such scores when $d_k=512$ with and without scaling.

  1. $\mathbb{E}[q_ik_i] = \mathbb{E}[q_i]\mathbb{E}[k_i] = 0$ and $\mathrm{Var}(q_ik_i) = \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] = 1$.
  2. Independence across $i$ gives $\mathrm{Var}(\sum_i q_ik_i) = \sum_i 1 = d_k$, so the standard deviation is $\sqrt{d_k}$.
  3. Dividing by $\sqrt{d_k}$ gives variance 1 and standard deviation 1. ∎
  4. For 100 independent standard normals the expected maximum is about 2.5. Without scaling and $d_k=512$, the scores have standard deviation $\approx22.6$, so the maximum is around $57$ — $e^{57}$ versus $e^{0}$ is a ratio of $10^{24}$, i.e. a completely saturated softmax. With scaling the maximum is $\approx2.5$ and the softmax behaves.
Hard

Count the parameters of a transformer block

For $d_{\text{model}} = d$, $h$ heads and an MLP expansion factor of 4, count the parameters of one pre-norm block (attention + MLP, ignoring LayerNorm) and evaluate for $d=768$, $h=12$.

  1. Attention: $W_Q, W_K, W_V$ each $d\times d$, plus $W_O$ $d\times d$: $4d^2$.
  2. MLP: $d\to4d$ and $4d\to d$: $4d^2 + 4d^2 = 8d^2$, plus biases $8d$.
  3. Total $\approx 12d^2$ (plus LayerNorm's $4d$). ∎
  4. For $d=768$: $12\cdot768^2 = 7{,}077{,}888$ parameters per block. A 12-block model (BERT-base) is therefore about 85M parameters — matching the published figure, with the remainder in the embedding matrix ($30{,}522\times768 \approx 23$M).
  5. Note that the head count does not appear: splitting into more heads keeps the parameter count constant because each head's width shrinks proportionally. Heads buy diversity, not capacity.
