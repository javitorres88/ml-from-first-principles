Model Interpretation & What Comes Next

Attribution as a research tool: linear weights, saliency, CAM and Grad-CAM; then Shapley values from cooperative game theory, their four axioms, and SHAP. Closes with vision transformers, contrastive learning, latent diffusion and neurosymbolic AI.

1 Intuition

The black-box problem

A model that maps input to output without exposing its reasoning creates two kinds of trouble: legal and scientific. Fair-lending law (ECOA, FCRA) requires credit decisions to be explainable — a bank cannot tell a rejected applicant "the score was 0.3" and stop there. And a scientist cannot debug, trust, or build on a model whose decisions they cannot inspect.

Model interpretation asks how a model arrives at its decision for a given sample. The dominant approach is attribution: explain the prediction in terms of the features that produced it.

ModelAttributed toWhy it matters
object recognition CNNpixels / regionsverify the model looks at the animal, not the background
text sentiment modelindividual wordscatch spurious cues such as negation or author names
credit modelapplication featureslegal requirement; detect discriminatory proxies

Attribution serves four jobs: debugging predictions, generating end-user explanations, analysing robustness, and extracting rules for knowledge discovery.

Two families of attribution

FamilyMethodsTrade-off
Architecture-specificlinear weights, random-forest feature importance, saliency maps (input gradients), CAM / Grad-CAMcheap and exact for their architecture, but not comparable across models
Model-agnosticSHAP (Shapley values), permutation importance, LIMEworks for anything, but approximate and expensive

Interpreting CNNs: saliency and CAM

Saliency maps take the gradient of the class score with respect to the input and use its magnitude as a per-pixel importance. Class Activation Mapping (Zhou et al., 2016) replaces the fully connected head with global average pooling, so the class score becomes a weighted sum of the final feature maps — and that weighted sum is a heatmap localised on the image.

Grad-CAM (Selvaraju et al., 2016) generalises this to any CNN, with or without a GAP head:

  1. Let the gradients of the target class score flow into the last convolutional layer.
  2. Average those gradients over each feature map $k$ to get an importance weight $\alpha_k$.
  3. Take a weighted sum of the feature maps, $\sum_k\alpha_kA^k$, and rectify with ReLU to keep only evidence for the class.

The result is coarse, because it is upsampled from a small feature map, so Guided Grad-CAM multiplies it element-wise with a guided-backpropagation saliency map to recover fine detail inside the coarse region.

Shapley values, from cooperative game theory

Cooperative game theory studies games in which coalitions of players collaborate to produce a payoff: formally a value function $v:2^D\to\mathbb{R}$ over subsets of the player set $D$. Lloyd Shapley (1953; Nobel Prize 2012) asked how the total payoff should be divided fairly. His answer is the unique allocation satisfying four axioms:

AxiomStatement
Null playera player who adds nothing to any coalition gets zero attribution
Efficiencythe attributions sum to the total payoff: $\sum_i\phi_i = v(D)$
Symmetryinterchangeable players receive equal credit
Linearityattribution of a weighted sum of games is the weighted sum of attributions

The map from features to model output is exactly a cooperative game: features are the players and the prediction is the payoff. SHAP (SHapley Additive exPlanations, Lundberg & Lee 2017) applies Shapley values to individual predictions, which is what popularised them in machine learning.

SHAP as a removal-based explanation

To evaluate a coalition $S$ you must decide what happens to the features not in $S$. SHAP averages the model output over all possible values of the missing features, weighted by their conditional probability given the observed ones:

$$ F(x_S) = \mathbb{E}_{x_{\bar S}\mid x_S}\big[f(x_S, x_{\bar S})\big] = \sum_{x_{\bar S}} f(x_S, x_{\bar S})\,p(x_{\bar S}\mid x_S) $$

Intuitively: fix the features you have, imagine every value the missing ones could take, and average the predictions. With $M$ features this needs $2^M$ coalition evaluations — infeasible beyond about 15 features, which is why KernelSHAP (a weighted least-squares approximation) and Monte Carlo permutation sampling exist.

The worked example from the lecture

A company with Alice and Bob: $v(\varnothing)=0$, $v(\{A\})=20$, $v(\{B\})=10$, $v(\{A,B\})=50$. Enumerate the two orderings. Alice first: she adds 20, Bob adds 30. Bob first: he adds 10, Alice adds 40. Averaging gives $\phi_A = (20+40)/2 = 30$ and $\phi_B = (30+10)/2 = 20$. They sum to 50 — efficiency holds — and the synergy is split evenly, because neither could produce it alone.

Where the field is going

DirectionIdea
Vision Transformersapply the standard transformer encoder to image patches; needs large-scale pretraining to beat CNNs
Contrastive learningpull augmented views of the same image together, push others apart — no labels needed
Latent diffusionrun the expensive reverse diffusion in a compressed latent space; the basis of Stable Diffusion
Neurosymbolic AIcombine learned perception with explicit reasoning, search and planning

Contrastive learning is worth understanding as a loss: given an anchor and a positive view, the model must pick the positive out of $2N-1$ candidates, which is cross-entropy over the batch with a temperature $\tau$. CLIP extends it to 400M image–text pairs, which is what enables zero-shot classification from a text prompt.

Diffusion models corrupt data with Gaussian noise over $T$ steps and learn to reverse it, trained by a simple denoising regression: predict the noise that was added. Latent diffusion runs that process inside a variational autoencoder's compressed space, and the text prompt enters through cross-attention — the same mechanism as module 12.

Moravec's paradox, and what is still missing

Things that are easy for humans (clearing a table, driving after 20 hours of practice) remain hard for AI, while things that are hard for humans (chess, exams) are easy. LeCun's diagnosis is that current systems lack world models learned from sensory input, persistent memory, the ability to plan, and safety by design. A four-year-old has processed more sensory data than the largest LLM was trained on — the missing ingredient may be the kind of data, not the amount.

2 Mathematical foundations

2.1 The Shapley value, defined and derived

For a game $v$ on player set $D$ with $|D|=M$, the Shapley value of player $i$ is

$$ \phi_i(v) = \sum_{S\subseteq D\setminus\{i\}}\frac{|S|!\,(M-|S|-1)!}{M!}\big[v(S\cup\{i\}) - v(S)\big] $$

The weight is the fraction of all $M!$ orderings in which exactly the players of $S$ precede $i$, so the formula is "average marginal contribution over all orderings".

Derivation — average marginal contribution over permutations
  1. Fix an ordering $\pi$. Player $i$'s marginal contribution is the increase in value when $i$ joins the set of players preceding it: $\Delta_i(\pi) = v(\mathrm{pre}(i)\cup\{i\}) - v(\mathrm{pre}(i))$.
  2. Define $\phi_i = \frac{1}{M!}\sum_{\pi}\Delta_i(\pi)$.
  3. Group the $M!$ orderings by $S = \mathrm{pre}(i)$. For $|S|=s$ the number of orderings realising that set is $s!\,(M-s-1)!$ — the orderings within $S$, times the orderings of the remaining players. Dividing by $M!$ gives the weight above. ∎
  4. Efficiency. Along any single ordering the marginals telescope to $v(D)-v(\varnothing)$; averaging preserves that, so $\sum_i\phi_i = v(D)$ when $v(\varnothing)=0$.
  5. Uniqueness. Shapley proved this is the only allocation satisfying the four axioms — the strongest justification any attribution method has.

2.2 The cost of exact Shapley values

ApproachComplexityFeasible for
Enumerate subsets$O(2^M)$about $M \le 15$
Enumerate permutations$O(M!)$about $M \le 8$
KernelSHAPweighted least squares over $O(2^M)$ samplesany $M$ with sampling
Monte Carlo permutations$O(M)$ per samplelarge $M$, approximate
TreeSHAP$O(TLD^2)$exact and fast for tree ensembles

The Monte Carlo estimator is just the permutation average over a random sample of orderings:

$$ \hat\phi_i = \frac{1}{m}\sum_{j=1}^{m}\Big[v\big(\mathrm{pre}_j(i)\cup\{i\}\big) - v\big(\mathrm{pre}_j(i)\big)\Big] $$

In practice $v(S)$ itself is estimated by replacing the missing features with values sampled from a background dataset — which is why SHAP explanations are stochastic and why the background set you choose changes the answer.

2.3 SHAP for a linear model

For $f(\mathbf{x}) = \mathbf{w}^\top\mathbf{x} + b$, the Shapley values are exactly

$$ \phi_i = w_i\big(x_i - \mathbb{E}[x_i]\big) $$
Why — and why the baseline matters
  1. With missing features replaced by their expectations, $v(S) = \sum_{i\in S}w_ix_i + \sum_{i\notin S}w_i\mathbb{E}[x_i] + b$.
  2. Adding player $i$ changes exactly one term, $w_ix_i - w_i\mathbb{E}[x_i]$, independent of $S$.
  3. Every ordering therefore gives the same marginal, so the average is that value. ∎
  4. Efficiency. $\sum_i\phi_i = f(\mathbf{x}) - \mathbb{E}[f(\mathbf{x})]$: the attributions sum to the difference between this prediction and the average prediction.
  5. This is why naive importance $w_ix_i$ misleads: it attributes part of the average prediction to every feature. Lab 2 shows both side by side.

2.4 Grad-CAM, formally

For class $c$, with $A^k$ the $k$-th feature map of the last convolutional layer and $y^c$ the class score:

$$ \alpha_k^c = \frac{1}{Z}\sum_i\sum_j\frac{\partial y^c}{\partial A^k_{ij}}, \qquad L^c_{\text{Grad-CAM}} = \mathrm{ReLU}\Big(\sum_k\alpha_k^c A^k\Big) $$

The ReLU is not cosmetic: features that push the score down for class $c$ do not explain why $c$ was predicted, so negative evidence is discarded. The map has the resolution of $A^k$ (often $7\times7$ for a $224\times224$ input), which is why it is coarse and needs upsampling.

2.5 The InfoNCE loss and temperature

Contrastive learning (SimCLR, MoCo) takes a batch of $N$ images, produces two augmented views of each, and requires every view to identify its partner among the $2N-1$ others. With cosine similarity $s_{i,j}$ and temperature $\tau$:

$$ L_i = -\log\frac{\exp(s_{i,i^+}/\tau)}{\sum_{j\ne i}\exp(s_{i,j}/\tau)} $$

This is exactly the softmax cross-entropy of module 04 with the positive pair as the correct class, and InfoNCE is a lower bound on the mutual information between the two views. Small $\tau$ sharpens the distribution and concentrates on the hardest negatives; large $\tau$ treats negatives more equally. Contrastive pretraining raised ImageNet linear-probe accuracy from the high 40s to above 80% — the largest single jump in self-supervised vision.

3 Interactive visualizations

Lab 1 · Shapley

A three-player cooperative game

Set the payoff of every coalition with the sliders. The bars are the exact Shapley values, computed by averaging each player's marginal contribution over all six orderings.

Check the efficiency readout: $\sum\phi$ always equals $v(ABC)$. That is not a coincidence, it is the axiom. Now make A and B perfect substitutes — set $v(AB) = v(A) = v(B)$ — and watch their attributions equalise. Then give C all the value and watch A and B collapse toward zero. The Shapley value is the only allocation that respects both symmetry and efficiency, which is why it is the default fair-credit rule.

Lab 2 · attribution

Raw contributions vs. SHAP

A linear model with three features. In raw mode the bars are $w_ix_i$ and they sum to $f(x)$ — which includes the model's average prediction, so a feature looks important just because it has a large typical value. In SHAP mode the bars are $w_i(x_i - \mathbb{E}[x_i])$ and they sum to $f(x) - \mathbb{E}[f]$.

Move a feature to zero and switch modes: in SHAP its bar vanishes (it is at its baseline, so it explains nothing), while in raw mode it still shows a contribution. That is the difference between "this feature is big" and "this feature is why the prediction differs from the average".

4 Coding from scratch

"""Module 16 — exact Shapley values and a permutation Monte Carlo estimate."""
import itertools
import random
from math import factorial


def shapley_exact(value_fn, players):
    """Average marginal contribution over all permutations."""
    M = len(players)
    phi = {p: 0.0 for p in players}
    for perm in itertools.permutations(players):
        before = []
        for p in perm:
            phi[p] += (value_fn(set(before) | {p}) - value_fn(set(before))) / factorial(M)
            before.append(p)
    return phi


def shapley_subsets(value_fn, players):
    """The closed form with the |S|!(M-|S|-1)!/M! weights — same answer, different route."""
    M = len(players)
    phi = {}
    for p in players:
        others = [q for q in players if q != p]
        total = 0.0
        for size in range(M):
            for subset in itertools.combinations(others, size):
                S = set(subset)
                w = factorial(size) * factorial(M - size - 1) / factorial(M)
                total += w * (value_fn(S | {p}) - value_fn(S))
        phi[p] = total
    return phi


def shapley_montecarlo(value_fn, players, samples=2000, seed=0):
    rng = random.Random(seed)
    M = len(players)
    phi = {p: 0.0 for p in players}
    for _ in range(samples):
        perm = players[:]
        rng.shuffle(perm)
        before = set()
        for p in perm:
            phi[p] += (value_fn(before | {p}) - value_fn(before)) / samples
            before.add(p)
    return phi


def check_axioms(value_fn, players, phi):
    """Efficiency and null-player sanity checks."""
    total = sum(phi.values())
    return {"sum_phi": round(total, 6), "v(all)": round(value_fn(set(players)), 6),
            "efficiency_holds": abs(total - value_fn(set(players))) < 1e-9}


if __name__ == "__main__":
    # The lecture's Alice/Bob game, plus a third player
    table = {frozenset(): 0, frozenset("A"): 20, frozenset("B"): 10, frozenset("C"): 5,
             frozenset("AB"): 50, frozenset("AC"): 30, frozenset("BC"): 20, frozenset("ABC"): 60}
    v = lambda s: table[frozenset(s)]

    phi = shapley_exact(v, ["A", "B", "C"])
    print("exact (permutations):", {k: round(x, 3) for k, x in phi.items()})
    print("exact (subsets)     :", {k: round(x, 3) for k, x in shapley_subsets(v, ["A", "B", "C"]).items()})
    print("monte carlo (2k)    :", {k: round(x, 3) for k, x in shapley_montecarlo(v, ["A", "B", "C"]).items()})
    print("axioms              :", check_axioms(v, ["A", "B", "C"], phi))

    # Two-player case from the slides
    v2 = lambda s: {frozenset(): 0, frozenset("A"): 20, frozenset("B"): 10, frozenset("AB"): 50}[frozenset(s)]
    print("\nAlice/Bob:", {k: round(x, 3) for k, x in shapley_exact(v2, ["A", "B"]).items()})

"""Module 16 — SHAP by hand for a linear model, plus saliency and Grad-CAM in NumPy."""
import numpy as np


def linear_shap(w, x, x_background):
    """For a linear model, phi_i = w_i (x_i - E[x_i]) exactly."""
    baseline = x_background.mean(axis=0)
    return w * (x - baseline), float(w @ baseline)


def montecarlo_shap(model, x, background, samples=200, seed=0):
    """Model-agnostic estimate: sample orderings, fill missing features from the background."""
    rng = np.random.default_rng(seed)
    M = len(x)
    phi = np.zeros(M)
    for _ in range(samples):
        perm = rng.permutation(M)
        before = []
        ref = background[rng.integers(len(background))]
        for p in perm:
            base = ref.copy()
            base[before] = x[before]
            with_p = base.copy()
            with_p[p] = x[p]
            phi[p] += (model(with_p[None])[0] - model(base[None])[0]) / samples
            before.append(p)
    return phi


def saliency(model_grad, x):
    """Magnitude of the input gradient, per pixel."""
    return np.abs(model_grad(x))


def grad_cam(feature_maps, grads, eps=1e-8):
    """feature_maps, grads: (C, H, W). Returns a (H, W) heatmap."""
    weights = grads.mean(axis=(1, 2))              # global-average-pooled gradients
    cam = np.maximum((weights[:, None, None] * feature_maps).sum(0), 0)
    cam = cam - cam.min()
    return cam / (cam.max() + eps)


def permutation_importance(model, X, y, metric, n_repeats=5, seed=0):
    """Drop in performance when each feature is shuffled."""
    rng = np.random.default_rng(seed)
    base = metric(y, model(X))
    imps = np.zeros(X.shape[1])
    for j in range(X.shape[1]):
        drops = []
        for _ in range(n_repeats):
            Xp = X.copy()
            rng.shuffle(Xp[:, j])
            drops.append(base - metric(y, model(Xp)))
        imps[j] = np.mean(drops)
    return imps


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    w = np.array([1.5, -2.0, 0.5])
    bg = rng.normal(0, 1, (200, 3))
    x = np.array([1.0, -1.0, 0.5])
    model = lambda X: X @ w + 0.3

    phi, base = linear_shap(w, x, bg)
    print("linear SHAP:", np.round(phi, 3), " baseline:", round(base, 3))
    print("sum(phi) vs f(x)-E[f]:", round(float(phi.sum()), 4), round(float(model(x[None])[0] - base), 4))

    mc = montecarlo_shap(model, x, bg, samples=400)
    print("monte carlo :", np.round(mc, 3), " (should approximate the above)")

    maps = rng.random((8, 7, 7))
    grads = rng.normal(0, 0.1, (8, 7, 7))
    heat = grad_cam(maps, grads)
    print("grad-cam heatmap:", heat.shape, " range:", round(float(heat.min()), 2), "to", round(float(heat.max()), 2))

"""Module 16 — SHAP in practice, plus Grad-CAM and attention visualisation."""
import numpy as np
import shap
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
names = list(load_breast_cancer().feature_names)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, stratify=y, random_state=0)

model = RandomForestClassifier(n_estimators=200, random_state=0).fit(X_tr, y_tr)

# ---- TreeSHAP: exact and fast for tree ensembles --------------------------
explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X_te[:100])
sv = shap_values[1] if isinstance(shap_values, list) else shap_values
print("shap values shape:", sv.shape)
print("efficiency check (first sample):",
      round(float(sv[0].sum()), 4), "vs",
      round(float(model.predict_proba(X_te[:1])[0, 1] - explainer.expected_value[1]), 4))

# ---- global importance: mean absolute SHAP ---------------------------------
importance = np.abs(sv).mean(0)
order = np.argsort(-importance)[:5]
print("\ntop features by mean |SHAP|")
for i in order:
    print(f"  {names[i]:24s} {importance[i]:.4f}")

# ---- a single prediction, explained ----------------------------------------
i = 0
print(f"\npatient 0: prediction {model.predict_proba(X_te[i:i+1])[0, 1]:.3f}")
for j in np.argsort(-np.abs(sv[i]))[:4]:
    print(f"  {names[j]:24s} value={X_te[i, j]:8.2f}  contribution={sv[i, j]:+.4f}")

# ---- KernelSHAP: model-agnostic, slower ------------------------------------
bg = shap.sample(X_tr, 50)
kernel_explainer = shap.KernelExplainer(model.predict_proba, bg)
ks = kernel_explainer.shap_values(X_te[:5], nsamples=200)
print("\nkernelshap shape:", np.array(ks).shape, "(model-agnostic, approximate)")

# ---- Grad-CAM in PyTorch, in five lines -----------------------------------
import torch
import torch.nn.functional as F

def grad_cam(model, x, layer, class_idx=None):
    feats, grads = {}, {}
    layer.register_forward_hook(lambda m, i, o: feats.__setitem__("v", o))
    layer.register_full_backward_hook(lambda m, gi, go: grads.__setitem__("v", go[0]))
    out = model(x)
    cls = out.argmax(1) if class_idx is None else torch.tensor([class_idx])
    out[0, cls].backward()
    w = grads["v"].mean(dim=(2, 3), keepdim=True)
    cam = F.relu((w * feats["v"]).sum(1, keepdim=True))
    cam = F.interpolate(cam, size=x.shape[-2:], mode="bilinear", align_corners=False)
    return (cam - cam.min()) / (cam.max() + 1e-8)

print("\ngrad_cam() defined — apply it to the CNN from module 10 with its last conv layer.")

5 Assessment

Quiz

Q1

The efficiency axiom of Shapley values states that:

$\sum_i\phi_i = v(D)$. This is what lets you say the SHAP values "add up" to the prediction (minus the baseline) — the property that makes them readable as a decomposition.

Q2

Why are exact Shapley values impractical for a model with 50 features?

Exact computation is $O(2^M)$ (subsets) or $O(M!)$ (permutations). KernelSHAP and Monte Carlo permutation sampling approximate the same quantity.

Q3

For a linear model $f(\mathbf{x}) = \mathbf{w}^\top\mathbf{x} + b$, the SHAP value of feature $i$ is:

Attribution is relative to the average prediction, so the baseline is subtracted. $w_ix_i$ sums to $f(x)$, not to $f(x)-\mathbb{E}[f]$ — a common source of misleading "importance" plots.

Q4

In Grad-CAM, why is the ReLU applied to the weighted sum of feature maps?

Regions that decrease the class score are irrelevant to explaining why the class was predicted. The ReLU removes them, leaving a heatmap of supporting evidence.

Q5

Contrastive learning (InfoNCE) is best described as:

With a temperature $\tau$, $L_i = -\log\frac{\exp(s_{i,i^+}/\tau)}{\sum_{j\ne i}\exp(s_{i,j}/\tau)}$ — literally the softmax cross-entropy of module 04 with the positive pair as the label.

Easy

Shapley by hand

Three players with $v(\varnothing)=0$, $v(A)=10$, $v(B)=0$, $v(C)=5$, $v(AB)=30$, $v(AC)=20$, $v(BC)=5$, $v(ABC)=40$. Compute all three Shapley values.

Enumerate the six orderings and record each player's marginal:

Orderingm(A)m(B)m(C)
A B C102010
A C B102010
B A C30010
B C A3505
C A B15205
C B A3505

Averages: $\phi_A = (10+10+30+35+15+35)/6 = 135/6 = 22.5$; $\phi_B = 60/6 = 10$; $\phi_C = 45/6 = 7.5$.

Check: $22.5+10+7.5 = 40 = v(ABC)$. ✓ B is a null player alone but earns 10 by complementing A — which is exactly what the symmetry axiom does not rule out.

Medium

Explain a loan rejection

A logistic model gives $P(\text{default}) = 0.31$ for an applicant, above the 0.25 threshold. The SHAP values are: income −0.12, debt-to-income +0.18, credit history −0.05, employment length +0.02, baseline $\mathbb{E}[f]=0.10$. Verify efficiency, identify the two features to cite in an adverse-action notice, and state one thing SHAP cannot tell you.

Efficiency. $0.10 + (-0.12+0.18-0.05+0.02) = 0.10 + 0.03 = 0.13$ — but the prediction is $0.31$. The gap is because SHAP for a probability output is computed on the probability scale and does not add up when the model is non-linear; the attributions above sum to the log-odds contribution, or the values were computed on a different scale. Check the scale before quoting them.

Cite. Debt-to-income (+0.18) is the dominant adverse factor, and income (−0.12) is the dominant mitigating factor. A notice should name debt-to-income as the principal reason.

What SHAP cannot tell you. Whether the model is right, whether debt-to-income is a proxy for a protected characteristic, or whether changing the debt ratio would actually change the outcome (attribution is not causation).

Hard

Show that SHAP for a linear model is exact, and generalise

Prove $\phi_i = w_i(x_i - \mathbb{E}[x_i])$ for $f(\mathbf{x}) = \mathbf{w}^\top\mathbf{x} + b$, then explain what changes if features are correlated.

  1. With independent features, the conditional expectation factorises: $\mathbb{E}[x_{\bar S}\mid x_S] = \mathbb{E}[x_{\bar S}]$, so $v(S) = \sum_{i\in S}w_ix_i + \sum_{i\notin S}w_i\mathbb{E}[x_i] + b$.
  2. Marginal contribution of $i$: $v(S\cup i) - v(S) = w_i(x_i - \mathbb{E}[x_i])$, independent of $S$; averaging over orderings leaves it unchanged. ∎
  3. Correlated features. Then $\mathbb{E}[x_{\bar S}\mid x_S] \ne \mathbb{E}[x_{\bar S}]$: knowing one feature tells you something about the others, so the marginal contribution of $i$ depends on which features are already in $S$. The Shapley values still satisfy the axioms, but they now split credit between correlated features — two identical features each receive half the attribution. That is usually the desired behaviour, but it means attributions are not stable under adding a duplicate column.
  4. Practical consequence: report SHAP alongside the correlation structure, and never interpret a single attribution for a correlated group as "the effect of that feature".

Project 16

An interpretability report a stakeholder can act on

Take a model you built earlier in this course and produce the explanation document that would accompany it in production.

Brief

  1. Pick a model from an earlier module with a real prediction task and a domain audience.
  2. Implement exact Shapley values for a small feature subset by hand, and verify them against shap on a model with the same features.
  3. Produce a global explanation (mean |SHAP| ranking, beeswarm) and a local explanation for three contrasting individuals.
  4. Add a shortcut audit: check whether any top-ranked feature is plausibly a proxy for something illegitimate, and test it by removing the feature and re-measuring.
  5. For an image or sequence model, add Grad-CAM or attention visualisations and describe what the model attends to.
  6. Write the caveats section: what attribution does not establish (causality, correctness, fairness).

Deliverables

  • From-scratch Shapley implementation with a test against shap
  • Global and local explanation figures
  • 2–3 page report with an explicit caveats section
