1 · Intuition first

A visual explanation and three real-world examples before a single symbol appears. If you cannot say what a model does in one sentence, the maths will not help.

2 · Mathematics, derived

Linear algebra, calculus and probability appear exactly where they are needed — with numbered, expandable derivations and proofs you can check line by line.

3 · Labs you can drag

Every module ships canvas-based simulations: sliders for learning rate, k, λ, C, γ, temperature. Break them on purpose. That is the fastest way to build intuition.

4 · Three implementations

Pure-Python from scratch (no libraries, so nothing hides), then vectorised NumPy, then the scikit-learn equivalent — with a note on when to use which.

5 · Assessment that bites

Multiple-choice quizzes with explanations for every distractor, a flashcard deck, and graded practice problems with full worked solutions.

6 · A portfolio project

Each module ends with a scoped project — brief, deliverables, rubric and starter code — so the course leaves you with artefacts, not just notes.

The mlfs Python library

Every code block in this course also exists as a tested module in the repository, so you can pip install -e . and run the exact code you read. Each algorithm ships with three implementations and a test suite that checks them against each other and against scikit-learn.

From scratch, then vectorised

from mlfs.linear_model import LinearRegressionScratch, LinearRegressionNumPy
from sklearn.linear_model import LinearRegression

m1 = LinearRegressionScratch().fit(X, y)   # loops + the normal equations
m2 = LinearRegressionNumPy().fit(X, y)     # vectorised, pinv-based
m3 = LinearRegression().fit(X, y)          # scikit-learn

assert abs(m1.coef_[0] - m3.coef_[0]) < 1e-8

What is inside

  • mlfs/ — 15 sub-packages covering the course (kNN, trees, SVM, PCA, CNN, RNN, attention, RL…)
  • tests/ — 53 tests, including parity checks against scikit-learn / NumPy references
  • assets/js/labs/ — the 16 lab scripts behind the interactive figures
  • projects/ — starter code and rubrics for the 16 portfolio projects

Dependencies: numpy, scikit-learn, pytest. PyTorch is optional and only used in the deep-learning notebooks.

Sources & attribution

The primary source for this site is the CSC 74020 Machine Learning lecture notes by Prof. Jonathan Gryak (Department of Computer Science, CUNY Graduate Center, Fall 2025): Lectures 1–14, including the slide decks for Transformers/LLMs, Dimensionality Reduction, SVMs, Reinforcement Learning and Model Interpretation. Notation, terminology, definitions, worked examples and the sequence of topics follow those notes closely.

Supplementary readings from the course reading list are referenced where a derivation benefits from a second treatment: Bishop, Pattern Recognition and Machine Learning (2006); Hastie, Tibshirani & Friedman, The Elements of Statistical Learning; Géron, Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow; Raschka, Machine Learning with PyTorch and Scikit-Learn; Zhang et al., Dive into Deep Learning; Sutton & Barto, Reinforcement Learning: An Introduction.

Interactive labs, code, quizzes, flashcards and projects are original to this repository. Figures are drawn in the browser with the small canvas toolkit in assets/js/viz.js — no charting library, no tracking, no network calls. Math is typeset with a locally vendored KaTeX.
