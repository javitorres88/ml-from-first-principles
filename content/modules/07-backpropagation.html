1 Intuition

Training = walking downhill, efficiently

Module 06 ended with a network whose parameters we cannot set by hand. Training means finding weights that minimise a loss, and the only tool that scales is gradient descent — but plain gradient descent on a deep network is too slow, and historically too fragile, to work. This module covers the two things that make it work: an efficient way to compute the gradient (backpropagation) and better ways to use it (momentum, adaptive learning rates).

Backpropagation, in the version published by Rumelhart, Hinton and Williams in 1986, is five steps:

  1. Initialise the weights (randomly, not at zero).
  2. Forward pass: feed a mini-batch through the network, storing every intermediate output.
  3. Loss: compare the output with the target.
  4. Reverse pass: compute each intermediate value's contribution to the loss using the multivariate chain rule, from the output backwards.
  5. Update: take a gradient-descent step on the weights.

The algorithm is reverse-mode automatic differentiation. Its magic is cost: computing the gradient of a scalar loss with respect to all parameters costs roughly the same as one forward pass — a small constant multiple, independent of how many parameters there are. That is what makes million-parameter models trainable at all.

Computation graphs and gradient routing

Draw every input and every computed value as a node, with a directed edge whenever one value is used to compute another. Then each edge carries a local gradient (how the child changes with the parent), and the chain rule says:

$$ \text{downstream} = \text{local gradient} \times \text{upstream gradient} $$

Start at the loss with upstream gradient $1$, walk backwards, and multiply as you go. Where a node has several consumers, their contributions add — that is the multivariate chain rule, and it is why a value used twice accumulates two gradients.

The flattening trick

Naively applying the chain rule repeats work. For $L = \frac12(\sigma(wx+b) - t)^2$ you compute $\sigma'(wx+b)$ once for $\partial L/\partial w$ and again for $\partial L/\partial b$. Flattening the nested function into named intermediates — $z = wx+b$, $y=\sigma(z)$, $L=\frac12(y-t)^2$ — lets you compute each local derivative once and reuse it: $\frac{dL}{dy} = y-t$, $\frac{dL}{dz} = \frac{dL}{dy}\sigma'(z)$, $\frac{\partial L}{\partial w} = \frac{dL}{dz}x$, $\frac{\partial L}{\partial b} = \frac{dL}{dz}$.

Shape analysis: how to remember the matrix gradients

You do not need to derive matrix calculus from scratch if you remember one rule: every gradient has the same shape as the thing it is a gradient of. For $Y = XW$ with $X\in\mathbb{R}^{N\times D}$ and $W\in\mathbb{R}^{D\times M}$:

$$ \frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y}W^\top \;\; (N\times D), \qquad \frac{\partial L}{\partial W} = X^\top\frac{\partial L}{\partial Y} \;\; (D\times M) $$

There is only one way to arrange those factors so the shapes come out right. This single observation replaces most of the matrix-calculus you would otherwise need.

Real-world examples

Frameworks · autograd

PyTorch and JAX

Every loss.backward() call builds a computation graph during the forward pass and walks it in reverse. Understanding the graph is understanding the framework.

Optimisation · defaults that work

Adam as the default

$\beta_1=0.9$, $\beta_2=0.999$, $\alpha=10^{-3}$ is a strong starting point for most models. Transformers, diffusion models and recommender systems are all trained this way.

Debugging · gradient checks

Numerical gradients

Before trusting a hand-written backward pass, compare it with central differences. A relative error above $10^{-6}$ means a bug — usually a transposed matrix or a missing factor.

Stability · initialisation

Xavier and He scaling

$\mathrm{std}=1/\sqrt{D_{\text{in}}}$ for tanh/sigmoid, $\sqrt{2/D_{\text{in}}}$ for ReLU. Get this wrong and a 20-layer network either dies or saturates before the first update.

Regularisation · dropout

Randomised training

Zeroing activations with probability $p$ prevents co-adaptation of features; at test time you scale by $1-p$ (or scale during training instead, "inverted dropout").

Practice · learning-rate schedules

Warmup then decay

Large models use a linear warmup followed by cosine or step decay. The learning rate is usually the single most important hyperparameter to tune.

2 Mathematical foundations

2.1 The chain rule, in the two forms you need

Univariate: if $f(x) = h(g(x))$ then $\frac{df}{dx} = \frac{dh}{dg}\cdot\frac{dg}{dx}$. For example $f(x) = (1+x^2)^3$ gives $f'(x) = 3(1+x^2)^2\cdot 2x = 6x(1+x^2)^2$.

Multivariate: if $f$ depends on $x(t)$ and $y(t)$, every path contributes:

$$ \frac{df}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} $$

This sum-over-paths is exactly what "gradients accumulate at nodes with multiple consumers" means in the graph.

2.2 Backpropagation through a two-layer MLP, derived

Take a network with one hidden layer, a scalar output and squared loss:

$$ \mathbf{z} = W^{(1)}\mathbf{x} + \mathbf{b}^{(1)},\quad \mathbf{h} = \sigma(\mathbf{z}),\quad y = W^{(2)}\mathbf{h} + b^{(2)},\quad L = \tfrac12(y-t)^2 $$
Derivation — all four gradients, then their matrix form
  1. Output: $\dfrac{dL}{dy} = y - t$. This is the base case: the derivative of the loss with respect to its own input.
  2. Output weights: $y = \sum_i w^{(2)}_i h_i + b^{(2)}$, so $\dfrac{\partial y}{\partial w^{(2)}_i} = h_i$ and $$ \frac{dL}{dw^{(2)}_i} = \frac{dL}{dy}\,h_i, \qquad \frac{dL}{db^{(2)}} = \frac{dL}{dy}. $$
  3. Hidden activations: $h_i$ influences $y$ only through $w^{(2)}_i$, so $$ \frac{dL}{dh_i} = \frac{dL}{dy}\,w^{(2)}_i. $$
  4. Pre-activations: $h_i = \sigma(z_i)$ and $z_i$ depends on $h_i$ only, so $$ \frac{dL}{dz_i} = \frac{dL}{dh_i}\,\sigma'(z_i). $$
  5. Hidden weights: $z_i = \sum_j w^{(1)}_{ij}x_j + b^{(1)}_i$, so $$ \frac{dL}{dw^{(1)}_{ij}} = \frac{dL}{dz_i}\,x_j, \qquad \frac{dL}{db^{(1)}_i} = \frac{dL}{dz_i}. $$
  6. Vectorised. With a batch $X\in\mathbb{R}^{N\times d}$ and per-sample loss vector, stacking the above: $$ \frac{dL}{dW^{(2)}} = \frac{dL}{d\mathbf{y}}\,\mathbf{h}^\top,\quad \frac{dL}{d\mathbf{h}} = W^{(2)\top}\frac{dL}{d\mathbf{y}},\quad \frac{dL}{d\mathbf{z}} = \frac{dL}{d\mathbf{h}}\odot\sigma'(\mathbf{z}),\quad \frac{dL}{dW^{(1)}} = \frac{dL}{d\mathbf{z}}\,\mathbf{x}^\top $$ where $\odot$ is the element-wise product. ∎
  7. Check the shapes: $W^{(1)}\in\mathbb{R}^{h\times d}$ and $\frac{dL}{d\mathbf{z}}\mathbf{x}^\top$ is $(h\times1)(1\times d) = h\times d$. ✓

2.3 Jacobians, and why you never build them

For a vector function $f:\mathbb{R}^m\to\mathbb{R}^n$ the Jacobian is the $n\times m$ matrix of partial derivatives, $[J_f]_{ij} = \partial f_i/\partial x_j$. Backpropagation multiplies the upstream gradient by a local Jacobian:

$$ \frac{\partial L}{\partial \mathbf{x}} = \underbrace{\frac{\partial \mathbf{z}}{\partial \mathbf{x}}}_{\text{Jacobian}}\;\underbrace{\frac{\partial L}{\partial \mathbf{z}}}_{\text{upstream}} $$

For an element-wise activation the Jacobian is diagonal, so the multiplication is an element-wise product — cheap. For a matrix multiply $Y = XW$ the Jacobian has $N^2DM$ entries; with $N=64$ and $D=M=4096$ that is 256 GB. You never form it: you apply the implicit multiplication $\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y}W^\top$, which costs one matmul. This is the single most important implementation insight in deep learning.

2.4 Momentum

Momentum replaces "position changes by the gradient" with "velocity accumulates the gradient, position changes by velocity":

$$ \mathbf{v}_{t+1} = \rho\,\mathbf{v}_t + \nabla f(\boldsymbol\theta_t), \qquad \boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \alpha\,\mathbf{v}_{t+1} $$

$\rho$ (typically 0.9 or 0.99) acts as friction. Two equivalent formulations appear in the literature; they differ only by whether $\alpha$ multiplies the gradient before or after the accumulation.

Why momentum helps — and how much
  1. Unroll the recursion: $\mathbf{v}_{t+1} = \sum_{k=0}^{t}\rho^{\,t-k}\nabla f(\boldsymbol\theta_k)$ — an exponentially decaying average of past gradients.
  2. Along a consistent direction (a shallow valley), the terms add coherently. The steady-state velocity is $\frac{1}{1-\rho}$ times the gradient, so with $\rho=0.9$ the effective step is $10\times$ larger.
  3. Across an oscillating direction, consecutive gradients alternate sign and cancel — the jitter is damped.
  4. For a quadratic with condition number $\kappa$, momentum reduces the iteration count from $O(\kappa)$ to $O(\sqrt{\kappa})$, with the optimal $\rho = \left(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\right)^2$. ∎

Why Adam needs bias correction
  1. Initialise $m_0 = 0$. After one step, $m_1 = (1-\beta_1)g_1$, which has expectation $(1-\beta_1)\mathbb{E}[g]$ — biased toward zero by a factor $1-\beta_1 = 0.1$.
  2. Unrolling: $\mathbb{E}[m_t] = (1-\beta_1)\sum_{k=1}^{t}\beta_1^{t-k}\mathbb{E}[g] = \big(1-\beta_1^t\big)\mathbb{E}[g]$.
  3. Dividing by $(1-\beta_1^t)$ therefore removes the bias exactly. At $t=1$ it multiplies the estimate by $10$, which is precisely what is needed. ∎
  4. Without correction the first steps are tiny (the second moment has the same problem with $1-\beta_2^t \approx 0.001$), and Adam behaves erratically at the start of training.

2.6 Initialisation: keep the variance constant

Derivation — Xavier (Glorot) initialisation

Consider one layer $y_i = \sum_{j=1}^{D_{\text{in}}} x_j w_j$ with $x$ and $w$ independent, zero-mean, and identically distributed.

  1. Variance of a sum of independent terms: $\mathrm{Var}(y_i) = D_{\text{in}}\,\mathrm{Var}(x_jw_j)$.
  2. For independent zero-mean variables, $\mathrm{Var}(xw) = \mathbb{E}[x^2]\mathbb{E}[w^2] - \mathbb{E}[x]^2\mathbb{E}[w]^2 = \mathrm{Var}(x)\mathrm{Var}(w)$.
  3. Hence $\mathrm{Var}(y_i) = D_{\text{in}}\,\mathrm{Var}(x)\,\mathrm{Var}(w)$.
  4. Requiring $\mathrm{Var}(y) = \mathrm{Var}(x)$ — no shrinkage, no blow-up, layer after layer — gives $$ \boxed{\;\mathrm{Var}(w) = \frac{1}{D_{\text{in}}}\;} \qquad \text{i.e. } \mathrm{std}(w) = \frac{1}{\sqrt{D_{\text{in}}}}. $$
  5. ∎ With ReLU, half the units are zeroed, which halves the variance, so the factor becomes $\sqrt{2/D_{\text{in}}}$ — the He initialisation. When $D_{\text{in}}\ne D_{\text{out}}$, the harmonic mean $D_{\text{avg}} = \frac{D_{\text{in}}+D_{\text{out}}}{2}$ is often used. For convolutional layers, $D_{\text{in}} = k^2\cdot C_{\text{in}}$.

2.7 Dropout and its test-time correction

During training, zero each activation with probability $p$ (typically 0.1–0.5). This prevents co-adaptation: no feature can rely on another always being present, so the network learns redundant representations. The trouble is that dropout makes the output random, and at test time we want a deterministic prediction — ideally the expectation over all $2^n$ masks.

Derivation — the $1-p$ scaling
  1. Consider one neuron with two inputs and weights $w_1,w_2$. During training with dropout on both inputs, the four equally likely masks give $$ y = \tfrac14\big[(w_1x_1 + w_2x_2) + (w_1x_1 + 0) + (0 + w_2x_2) + 0\big] = \tfrac12(w_1x_1 + w_2x_2). $$
  2. At test time all inputs are present, giving $w_1x_1 + w_2x_2$ — exactly twice the training-time expectation.
  3. So either scale the weights by $1-p$ at test time, or (equivalently, and now standard) divide the surviving activations by $1-p$ during training. This is inverted dropout: training and testing then use the same code path. ∎

This "add randomness in training, average it out at test time" pattern also describes batch normalisation, and it is the same idea that later appears as data augmentation and as stochastic depth in modern architectures.

4 Coding from scratch

"""Module 07 — backprop from scratch on a scalar computation graph + gradient check."""
import math


def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z)) if z >= 0 else math.exp(z) / (1.0 + math.exp(z))


def f(x, y, z):
    """f = (x + y) * sigmoid(z)"""
    return (x + y) * sigmoid(z)


def grads(x, y, z):
    """Reverse-mode differentiation, written out node by node."""
    q = x + y                     # forward
    s = sigmoid(z)
    out = q * s

    dout = 1.0                    # base case
    dq = dout * s                 # multiply node: local gradient = the other input
    ds = dout * q
    dz = ds * s * (1 - s)         # sigmoid node
    dx = dq * 1.0                 # add node: local gradient = 1
    dy = dq * 1.0
    return out, {"x": dx, "y": dy, "z": dz}


def numeric_grad(fn, args, i, h=1e-5):
    """Central difference w.r.t. argument i."""
    a = list(args); b = list(args)
    a[i] += h; b[i] -= h
    return (fn(*a) - fn(*b)) / (2 * h)


def check(x, y, z):
    _, g = grads(x, y, z)
    worst = 0.0
    for i, name in enumerate("xyz"):
        n = numeric_grad(f, (x, y, z), i)
        rel = abs(g[name] - n) / max(1e-8, abs(g[name]) + abs(n))
        worst = max(worst, rel)
        print(f"  d/d{name}: analytic={g[name]: .6f}  numeric={n: .6f}  rel err={rel:.2e}")
    return worst


if __name__ == "__main__":
    print("gradient check at (x,y,z) = (-2, 5, -4):")
    print("  worst relative error:", f"{check(-2, 5, -4):.2e}")
    print("gradient check at a random point:")
    print("  worst relative error:", f"{check(0.3, -1.7, 2.2):.2e}")

"""Module 07 — a full MLP with manual backprop, plus SGD/momentum/RMSProp/Adam."""
import numpy as np


def init_mlp(sizes, scheme="he", seed=0):
    rng = np.random.default_rng(seed)
    params = []
    for n_in, n_out in zip(sizes[:-1], sizes[1:]):
        std = np.sqrt(2.0 / n_in) if scheme == "he" else np.sqrt(1.0 / n_in)
        params.append([rng.normal(0, std, (n_in, n_out)), np.zeros(n_out)])
    return params


def forward(X, params):
    cache = []
    A = X
    for i, (W, b) in enumerate(params):
        Z = A @ W + b
        A = np.maximum(Z, 0) if i < len(params) - 1 else Z   # ReLU hidden, linear output
        cache.append((A, Z))
    return A, cache


def backward(X, T, params, cache):
    """Returns gradients with the same structure as params."""
    grads = [None] * len(params)
    n = X.shape[0]
    dA = 2 * (cache[-1][0] - T) / n                      # dL/dOutput for MSE
    for i in reversed(range(len(params))):
        A_prev = X if i == 0 else cache[i - 1][0]
        Z = cache[i][1]
        dZ = dA if i == len(params) - 1 else dA * (Z > 0)
        dW = A_prev.T @ dZ
        db = dZ.sum(axis=0)
        grads[i] = [dW, db]
        dA = dZ @ params[i][0].T
    return grads


class SGDMomentum:
    def __init__(self, params, lr=0.05, rho=0.9):
        self.lr, self.rho = lr, rho
        self.v = [[np.zeros_like(p) for p in layer] for layer in params]

    def step(self, params, grads):
        for i, layer in enumerate(params):
            for j in range(len(layer)):
                self.v[i][j] = self.rho * self.v[i][j] + grads[i][j]
                layer[j] -= self.lr * self.v[i][j]


class Adam:
    def __init__(self, params, lr=1e-3, b1=0.9, b2=0.999, eps=1e-8):
        self.lr, self.b1, self.b2, self.eps, self.t = lr, b1, b2, eps, 0
        self.m = [[np.zeros_like(p) for p in layer] for layer in params]
        self.v = [[np.zeros_like(p) for p in layer] for layer in params]

    def step(self, params, grads):
        self.t += 1
        for i, layer in enumerate(params):
            for j in range(len(layer)):
                g = grads[i][j]
                self.m[i][j] = self.b1 * self.m[i][j] + (1 - self.b1) * g
                self.v[i][j] = self.b2 * self.v[i][j] + (1 - self.b2) * g * g
                mh = self.m[i][j] / (1 - self.b1 ** self.t)
                vh = self.v[i][j] / (1 - self.b2 ** self.t)
                layer[j] -= self.lr * mh / (np.sqrt(vh) + self.eps)


def grad_check(X, T, params, eps=1e-6):
    """Compare analytic and numerical gradients for every parameter."""
    out, cache = forward(X, params)
    grads = backward(X, T, params, cache)
    worst = 0.0
    for i, layer in enumerate(params):
        for j in range(len(layer)):
            flat = layer[j].ravel()
            for k in range(min(flat.size, 8)):
                old = flat[k]
                flat[k] = old + eps
                lp, _ = forward(X, params)
                flat[k] = old - eps
                lm, _ = forward(X, params)
                flat[k] = old
                num = (np.mean((lp - T) ** 2) - np.mean((lm - T) ** 2)) / (2 * eps)
                ana = grads[i][j].ravel()[k]
                worst = max(worst, abs(num - ana) / max(1e-8, abs(num) + abs(ana)))
    return worst


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    X = rng.normal(size=(32, 5))
    T = np.sin(X[:, :1]) + 0.1 * rng.normal(size=(32, 1))

    params = init_mlp([5, 16, 16, 1])
    print("worst relative gradient error:", f"{grad_check(X, T, params):.2e}")

    opt = Adam(params, lr=5e-3)
    for epoch in range(300):
        out, cache = forward(X, params)
        g = backward(X, T, params, cache)
        opt.step(params, g)
        if epoch % 100 == 0:
            print(f"epoch {epoch:3d}  MSE = {np.mean((out - T) ** 2):.5f}")

"""Module 07 — the same thing in PyTorch, to see what the framework automates."""
import torch
import torch.nn as nn
import torch.optim as optim

# --- 1. Autograd: the computation graph is built for you -------------------
x = torch.tensor([-2.0], requires_grad=True)
y = torch.tensor([5.0], requires_grad=True)
z = torch.tensor([-4.0], requires_grad=True)
f = (x + y) * torch.sigmoid(z)
f.backward()
print("autograd:", x.grad.item(), y.grad.item(), z.grad.item())

# --- 2. A model, an optimiser, and the training loop ------------------------
torch.manual_seed(0)
X = torch.randn(256, 5)
T = torch.sin(X[:, :1]) + 0.1 * torch.randn(256, 1)

model = nn.Sequential(
    nn.Linear(5, 16), nn.ReLU(),
    nn.Linear(16, 16), nn.ReLU(),
    nn.Linear(16, 1),
)

for opt_name, opt_cls, kwargs in [
    ("SGD", optim.SGD, {"lr": 0.05}),
    ("SGD+momentum", optim.SGD, {"lr": 0.05, "momentum": 0.9}),
    ("RMSProp", optim.RMSprop, {"lr": 0.01}),
    ("Adam", optim.Adam, {"lr": 5e-3}),
]:
    torch.manual_seed(0)
    m = nn.Sequential(nn.Linear(5, 16), nn.ReLU(), nn.Linear(16, 16), nn.ReLU(), nn.Linear(16, 1))
    opt = opt_cls(m.parameters(), **kwargs)
    for step in range(400):
        loss = nn.functional.mse_loss(m(X), T)
        opt.zero_grad()
        loss.backward()
        opt.step()
    print(f"{opt_name:14s} final MSE = {loss.item():.5f}")

# --- 3. Initialisation and dropout -----------------------------------------
def init_weights(m):
    if isinstance(m, nn.Linear):
        nn.init.kaiming_normal_(m.weight, nonlinearity="relu")   # He init
        nn.init.zeros_(m.bias)

model.apply(init_weights)
drop = nn.Sequential(nn.Linear(5, 16), nn.ReLU(), nn.Dropout(p=0.3), nn.Linear(16, 1))
print("dropout is identity at eval:", torch.allclose(drop.eval()(X), drop.eval()(X)))
print("dropout is random at train:", not torch.allclose(drop.train()(X), drop.train()(X)))
Read the three blocks in order: the first shows what a gradient is, the second shows how to compute it and how four optimisers consume it, the third shows the two lines of PyTorch that replace the middle block — and the four optimiser names that are the same four algorithms.
Debugging checklist for a backward pass
  1. Gradient-check on a tiny batch (8 samples, 2 layers) before scaling up.
  2. If the loss is nan: check for log(0), division by zero, or a learning rate that is too large.
  3. If only the last layer learns: suspect a missing non-linearity or a vanishing gradient.
  4. If the loss does not move: verify that zero_grad() is called (PyTorch accumulates by default).

5 Assessment

Quiz

Q1

For $Y = XW$ with $X\in\mathbb{R}^{N\times D}$ and $W\in\mathbb{R}^{D\times M}$, the gradient with respect to $W$ is:

Shape analysis: $\partial L/\partial W$ must be $D\times M$, and $X^\top$ is $D\times N$ while $\partial L/\partial Y$ is $N\times M$ — the only arrangement that works. Option C is $\partial L/\partial X$.

Q2

Momentum with $\rho=0.9$ along a direction where the gradient is constant multiplies the effective step size by about:

The velocity reaches steady state $v = g/(1-\rho) = 10g$. Momentum reduces the iteration count for a quadratic from $O(\kappa)$ to $O(\sqrt\kappa)$.

Q3

Why does Adam divide by $(1-\beta_1^t)$ and $(1-\beta_2^t)$?

After $t$ steps, $\mathbb{E}[m_t] = (1-\beta_1^t)\mathbb{E}[g]$. Dividing by that factor removes the bias exactly, which matters most at $t=1$ where $1-\beta_1 = 0.1$.

Q4

Xavier initialisation sets $\mathrm{std}(w) = 1/\sqrt{D_{\text{in}}}$ in order to:

$\mathrm{Var}(y) = D_{\text{in}}\mathrm{Var}(x)\mathrm{Var}(w)$, so $\mathrm{Var}(w) = 1/D_{\text{in}}$ makes $\mathrm{Var}(y) = \mathrm{Var}(x)$. For ReLU the factor becomes $\sqrt{2/D_{\text{in}}}$ (He).

Q5

With inverted dropout (dividing by $1-p$ during training), what happens at inference?

Scaling during training makes the expected activation at training time equal the actual activation at test time, so inference is the plain forward pass.

Term
Local vs. upstream gradient
Definition
Local: how a node's output changes with its input. Upstream: how the loss changes with the node's output. Their product is the downstream gradient.
Term
Reverse-mode autodiff
Definition
Compute the gradient of one scalar output w.r.t. all inputs in a single backward sweep, at roughly the cost of one forward pass. What backpropagation is.
Term
Gradient accumulation
Definition
At a node used by several consumers, downstream gradients add. This is the multivariate chain rule and the reason loss.backward() must be preceded by zero_grad().
Term
Condition number
Definition
Ratio of largest to smallest Hessian eigenvalue. High $\kappa$ means an elongated valley: SGD jitters across the steep direction and crawls along the shallow one.
Term
AdaGrad's flaw
Definition
The denominator accumulates all past squared gradients, so the effective learning rate decays to zero and training stalls. RMSProp fixes it with an exponential average.
Term
Bias correction
Definition
Divide the running moment by $1-\beta^t$ so that it is an unbiased estimate of the true moment even at $t=1$.
Term
Dropout at test time
Definition
All units active. With inverted dropout the scaling already happened during training, so inference is the ordinary forward pass.
Term
He initialisation
Definition
$\mathrm{std} = \sqrt{2/D_{\text{in}}}$ for ReLU networks: the factor 2 compensates for the half of units that ReLU zeroes out.

Practice problems

Easy

Backprop by hand

For $f(a,b,c) = (a+b)\cdot c^2$ with $a=1$, $b=-2$, $c=3$: draw the graph and compute $\partial f/\partial a$, $\partial f/\partial b$, $\partial f/\partial c$.

Forward: $q = a+b = -1$; $s = c^2 = 9$; $f = q\cdot s = -9$.

Backward: $\partial f/\partial f = 1$; $\partial f/\partial q = s = 9$; $\partial f/\partial s = q = -1$.

$\partial f/\partial a = 9\cdot1 = 9$; $\partial f/\partial b = 9\cdot1 = 9$; $\partial f/\partial c = -1\cdot 2c = -6$.

Sanity check: increasing $c$ by 0.01 changes $f$ by about $-0.06$. ✓

Medium

Derive the vectorised gradients

For a batch of $N$ samples, $Z = XW^{(1)}+\mathbf{b}^{(1)}$, $H=\mathrm{ReLU}(Z)$, $O = HW^{(2)}+\mathbf{b}^{(2)}$, and $L = \frac{1}{2N}\|O-T\|_F^2$, derive $\partial L/\partial W^{(2)}$, $\partial L/\partial H$, $\partial L/\partial Z$, $\partial L/\partial W^{(1)}$ and verify each shape.

  1. $\dfrac{\partial L}{\partial O} = \dfrac{1}{N}(O-T)$, shape $N\times k$.
  2. $\dfrac{\partial L}{\partial W^{(2)}} = H^\top\dfrac{\partial L}{\partial O}$, shape $(N\times h)^\top(N\times k) = h\times k$ ✓. $\dfrac{\partial L}{\partial \mathbf{b}^{(2)}} = \mathbf{1}^\top\dfrac{\partial L}{\partial O}$, shape $k$ ✓.
  3. $\dfrac{\partial L}{\partial H} = \dfrac{\partial L}{\partial O}W^{(2)\top}$, shape $(N\times k)(k\times h) = N\times h$ ✓.
  4. $\dfrac{\partial L}{\partial Z} = \dfrac{\partial L}{\partial H}\odot\mathbb{1}[Z\gt0]$, same shape $N\times h$ ✓ (ReLU's local Jacobian is diagonal).
  5. $\dfrac{\partial L}{\partial W^{(1)}} = X^\top\dfrac{\partial L}{\partial Z}$, shape $d\times h$ ✓; $\dfrac{\partial L}{\partial \mathbf{b}^{(1)}} = \mathbf{1}^\top\dfrac{\partial L}{\partial Z}$ ✓. ∎
Hard

Why the memory is the problem

For a layer with $N=64$ samples, $D=M=4096$, estimate the size of the full Jacobian $\partial Y/\partial X$, and show that the implicit product costs only $O(NDM)$ time and $O(ND+NM)$ memory.

  1. $Y = XW$ has $NM$ outputs and $X$ has $ND$ inputs, so the Jacobian has $(NM)\times(ND)$ entries $= 64\cdot4096\cdot64\cdot4096 \approx 6.9\times10^{10}$ values. In float32 that is about 274 GB.
  2. The implicit product $\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y}W^\top$ is one matrix multiply: $2NDM \approx 2.1\times10^{9}$ flops and stores only the $N\times D$ result.
  3. Memory for the forward pass is $O(ND + NM)$ — the activations, not the Jacobians. ∎
  4. This is why frameworks store activations ("checkpointing" trades memory for recomputation) and why a batch that is twice as large needs roughly twice the activation memory.

A mini autograd engine

Build the thing that makes PyTorch PyTorch: a small reverse-mode automatic differentiation library with a handful of operations, then use it to train a real network.

Brief

  1. Implement a Tensor class that records its parents and a local backward function, supporting +, *, @, exp, log, tanh, relu, sum, mean and broadcasting.
